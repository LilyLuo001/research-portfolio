# 后续清洗的执行边界

本轮目标是形成可审计的资格与技能测量，支持“计算机化与 AI 如何改变不同经验的作用”的比较。所有阶段保留分母，分开基础结构验收、工程试跑与语义验收。

1. **基础层可继续用。** 美国 Records、日期风险、正文匹配、官方职业成员标记及 remote 的可观察起始期，先组成覆盖报告。`JOB_HASH` 连接唯一不代表正文历史版本已获证明。
2. **V4 冻结为诊断基准。** 24 条新盲读记录与旧版本预测均保留；当前不放行正式学历/经验二元结果。小批真实文本仅测工程吞吐，不用其比例推断全国招聘要求。
3. **V5 只做一次结构修正。** 资格存在、条件强度、经验范围和替代关系分别保存。曾用来改规则的文本列入开发排除清单。未找到证据、明确不要求和无法判断是三种状态。
4. **按模块验收，避免整套反复返工。** 下一轮先校准一般经验年限和学历条件是否出现及其强度，再扩职业/领域/工具经验、任务与资格替代。每个模块单独报告漏报、误报、未知和适用样本；合取/析取复杂路径未验收前不输出联合最低门槛。
5. **两区同版本、不同分片。** 使用已去重的 2,464 个分片清单；region/source_file/source_row/JOB_HASH、原文指纹、规则版本、证据片段及坐标均保留。两区结果按这些来源键合并，不按职位标题去重。
6. **正式输出控制体积。** 工程小批保存完整候选 JSON 便于查错；未来全量优先输出分列 Parquet 的广告状态、证据、关系三张表，避免每条重复保存完整正文。原始正文持续保留，可按固定标准化版本重建证据坐标。未测真实膨胀率前，不把小试空间按文件压缩比直接外推。
7. **统计分析时点。** 正文结果先称“首次观察队列对应的交付文本特征”；remote 不能向前回填。共同技术/经验分类冻结后才能比較，不能按年份把所有旧工具叫计算机化、所有新工具叫 AI。

Revelio 履历约 1TB 尚未上传。当前先保留可与履历对齐的雇主—岗位族—地区—季度接口，不假定广告能逐条匹配到被录用者。新的外部数据迁移与存储安排不在本轮任务中。
