# O*NET 官方代码成员核验

2026-09-27 下载并核对 [O*NET-SOC 2019 官方职业列表](https://www.onetcenter.org/taxonomy/2019/list.html)，完整 1,016 个唯一代码。对已有全部美国季度职业汇总进行逐码核验，未重扫原文。

- 全部分母：253,210,047 条 Records。
- 官方 2019 列表成员：253,078,004 条，约 99.9479%；观察到 1,012 种官方代码。
- 代码 `99-9999.00`：45,752 条，保留为非官方占位类别，不作为实际职业组。
- 其余不在 2019 列表的非空代码：69 条，保留为版本/映射待核，不武断判错或自动映射到最新职业。
- O*NET 键缺失：82,795 条；空代码：3,427 条。

原有 `valid` 仅表示字符串格式匹配，不能读成官方职业有效。本次衍生表 `quarter_full_code_flagged.parquet` 新增 taxonomy_membership，保留全部记录并守恒，不覆盖原表。进入职业主分析时应使用该成员标记，同时保留缺失/占位分母用于覆盖报告。

这只验证代码是否属于指定官方列表，不能验证供应商对具体职位分类是否准确，也不证明该代码在广告发布当时已可观测。少量非成员代码的版本转换暂不强制完成。
