# LinkUp 招聘正文时间归属风险报告

**报告版本：2026-09-25，昆山已完成样本。此报告不是全库最终结果，也不等于全部正文清洗完成。**

## 1. 范围与结论

本次覆盖昆山固定的 **1,358 个 Description 文件**，占计划 2,464 个文件的 55.11%；文件数比例不代表行数或代表性。文件按下载、传输安排划分，并非随机抽样。华中尚在处理的文件不包含在本报告内。连接基准是完整的 269 个 Job Records 文件，共 **356,449,214 条记录**。

当前 Description 共 164,581,116 个不同 JOB_HASH，成功匹配 164,566,138 个（99.99%），未匹配 14,978 个；已匹配记录中公司 ID 冲突为 0。该匹配率的分母是本批 Description 的键，不能读成“全体 Records 的正文覆盖率”。美国严格按 COUNTRY="USA" 界定，匹配美国广告共 **112,836,465 个键**。JOB_HASH 是本次广告记录单位，不代表实际招聘人数或独立职位空缺数。

主要判断：跨季度的潜在时间归属问题不能忽略。**2022Q4 在 11 月 30 日前首次出现的有效广告中，44.89% 的观察区间跨过该界线，明显高于全历史总体的 2.70%。** 因此，总体比例不能替代临近界线样本的时间归属审查。当前数据没有独立正文时间戳，仍无法证实关闭后正文固定或历史版本保留。

**2026-09-25 补充的一对一连接核验：** 完整 Records 的 356,449,214 行均为非空且全局唯一 JOB_HASH；昆山 1,358 个 Description 文件的 164,581,116 行也均为非空且唯一键。连接后的 164,581,116 行恰为 164,566,138 个成功匹配键加 14,978 个孤立描述键，没有行数膨胀。因此，本批成功匹配严格为 1:1，描述端匹配率为 99.9909%。这是广告记录与正文的唯一对应关系；广告首次出现等日期可以通过连接唯一取回。正文是否为该广告首次出现时的文本，仍属于版本语义问题，与连接是否唯一是两项不同检查。跨两地全部描述的重复键核验需在华中完成后补齐。证据见 [一对一核验说明](/Users/lilyluo/Documents/LinkUp_Research_20260924/reports/job_hash_join_evidence/JOB_HASH_1TO1_EVIDENCE_CN.md)。

## 2. 统计定义与分母

- 主口径：CREATED → LAST_CHECKED，表示供应商首次至最近观察到的时间包络。它不保证期间连续活跃，也不表明当前正文在整个期间有效。
- 替代口径：CREATED → DELETE_DATE，只针对起止均有值且顺序正确的记录。DELETE_DATE 缺失不自动等于当前仍在招聘。两种口径的样本和终点不同，不应当作风险的数学上下界。
- 有效日期：起止非缺失、终点不早于起点，且均不晚于冻结上界 2026-09-06 23:59:59 UTC。
- 跨季度比较“年＋季度”；跨年也计入跨季度。表内跨年是跨季度的子集，二者不能相加。
- 跨界线定义：CREATED < 界线，且终点 ≥ 界线。使用 2022-11-30 00:00 UTC 与 2023-01-01 00:00 UTC；这是研究分期，不是企业实际采用 AI 的时间。
- 跨 AI 界线同时给出“全部有效日期广告”和“界线前首次出现且日期有效广告”两个分母，后者称为条件比例。

## 4. 日期缺失与异常

以下计数均以本批 112,836,465 个匹配美国广告为基础；不同异常可能重叠，不能把整张表机械相加。

| 日期检查 | 广告数 |
|---|---:|
| CREATED 缺失 | 0 |
| LAST_CHECKED 缺失 | 0 |
| LAST_CHECKED 早于 CREATED | 83 |
| DELETE_DATE 缺失 | 1,926,408 |
| DELETE_DATE 早于 CREATED | 453 |
| LAST_UPDATED 缺失 | 97,983,834 |
| LAST_UPDATED 早于 CREATED | 375 |
| LAST_UPDATED 晚于 LAST_CHECKED | 105,200 |
| 四个日期字段分别晚于冻结上界 | 各 0 |

主口径有效日期分母：112,836,465 − 83 = 112,836,382。替代口径有效日期分母：112,836,465 − 1,926,408 − 453 = 110,909,604。这两项分母守恒已经验证。

**LAST_UPDATED 缺失率为 86.84%。** 不能把缺失解释为“从未更新”，也不能把该字段直接当作正文版本日期。其与其他日期不一致的记录应保留异常标记；本报告未用 LAST_UPDATED 作为主区间终点。

## 5. 风险分布：企业、首次观察时期与州

### 5.1 首次观察时期：临近分界线的风险明显高于总体

**2022Q4 中在 11 月 30 日前首次出现的有效广告，44.89% 的观察区间跨过该界线。** 因而不能用全历史总体的 2.70% 判断临近 AI 分界线样本的时间归属风险。

| 首次观察队列 | Nov-30 前有效分母 | 跨 Nov-30 数量 | 条件比例 | 占全部跨 Nov-30 广告 |
|---|---:|---:|---:|---:|
| 2022 年 | 12,113,266 | 1,592,022 | **13.14%** | 84.23% |
| 2022Q3 | 3,135,289 | 426,230 | **13.59%** | 22.55% |
| 2022Q4 | 1,965,326 | 882,243 | **44.89%** | 46.68% |

2022Q4 的分母只含 11 月 30 日前首次出现的广告，不含该季度之后出现的广告。该子样本仅占全历史界线前有效分母的 **2.81%**，却贡献 **46.68%** 的跨界线广告。替代终点 DELETE_DATE 下，Q4 的对应比例为 **48.88%**（960,001 / 1,963,995）。改用 2023-01-01 分期时，2022Q4 主口径条件比例仍为 **36.63%**（1,061,689 / 2,898,654）；此时分母覆盖该季度所有有效广告，不能与 Nov-30 表当作同一人群的变化。

这与“越靠近界线首次出现，越容易仍被观察到跨过界线”的时间结构相容；并不证明 AI 延长了广告寿命或修改了招聘要求。2022 年队列占全历史界线前有效分母 17.33%，贡献跨界广告 84.23%，说明长期总体会稀释临近事件窗口的风险。

| 前 50 家 | 27.43% | 14.24% | 14.51% |

前 10 家的跨界份额高于其分母份额，但这一排序本身按跨界数量选取，差异也可能由企业的首次观察队列、职位组合和观察时间构成造成。它是需要进一步检查的集中度事实，不是控制这些差异后的企业效应。

原门槛覆盖 26,963 家企业，其中 21,750 家有非零的界线前有效分母。逐企业计算条件比例、每家企业等权后：中位数 **2.13%**、第 75 百分位 **5.16%**、第 90 百分位 **10.71%**；全样本广告加权条件比例为 2.70%。二者权重和样本范围不同。

## 6. 关闭后最后正文是否固定保留

**补充核查（2026-09-25，官方交付文档与 Dewey 清单）：缺少行级正文时间戳，不等于供应商没有带日期的交付文件。** LinkUp 官方列出了带日期文件名的每日正文文件和月度全量包；其正文表字段定义本身只列 hash、description。我们实际下载的是 Dewey 的 Job Descriptions 数据集导出，版本时间为 `2026-09-06T04:57:24.018000+00:00`，导出时间为 `2026-09-06T08:11:37.798870+00:00`，共 2,464 个文件，清单中日期分区列和分区键均为空。截图文件名与 Dewey 原清单一致，并非清洗时移除了文件名中的日期。

这些已知日期标记版本或导出批次，不能直接赋给每条正文作为其首次出现或最后修改时间。是否存在可取得的原始每日历史文件、逐月历史快照或分片至源文件日期的映射，尚未确认；也没有证据据此断言 Dewey 已丢失或覆盖所有旧版本。若取得完整带日期历史交付，并确认增量如何记录修改，可以补充构建正文的观测历史。因此，当前结论是“本次导出尚未识别出正文历史时间轴”，不是“LinkUp 不存在历史时间信息”。见 [官方数据字典](https://data.support.linkup.com/kb/article/56-data-dictionary-raw-data-package-feeds/?section_id=7)；本目录 `description_delivery_timestamp_audit.json` 保留本次导出证据。

**结论：未确认，现有计算无法回答“是”。** Description 当前快照没有独立正文时间戳或可验证的正文版本序列。本次匹配与时间诊断读取键及 Records 日期，没有读取正文进行历史版本比对。

当前证据可以确认键能否匹配、观察区间是否跨期，不能确认当前文本属于首次发布时、最后观察时或其他时点；不能证明广告关闭后正文不再变化，也不能排除 URL 重用、重新出现或历史内容覆盖。即使区间落在同一季度，也不证明当前文本在 CREATED 时已经存在。

需向供应商核实：DESCRIPTION 是首次、最近还是其他规则选择的正文；正文改写是否保留旧版本及时间；广告关闭后是否仍更新；URL 重新出现时如何处理；LAST_UPDATED 的触发条件和缺失含义；能否提供带日期的历史快照或版本样例。当前报告不将任何一项未获证实的机制当作事实。

## 7. 对研究设计的处理建议与交付边界

在供应商确认正文历史语义前，可以继续构建 Records 的首次出现、最近观察和删除等面板，但不应将当前正文要求直接回填到历史月份，并据此宣称要求随 AI 发生变化。若最终无法取得版本历史，正文分析的时间解释与识别设计需要调整；单靠排除跨界线广告不能独自解决这一问题。

1. 在匹配输出中保留两套观察区间、跨季度/年/两条界线标记及日期异常状态。当前 Description 不直接命名为“首次发布时的招聘要求”。
2. 对 AI 前后要求变化，先检查靠近分界线的首次观察队列和企业，再做完整样本、去除跨界线广告等敏感性比较。去除跨期广告本身可能选择性排除长时间存在的广告，不应自动作为无偏的主样本。
3. 华中数据完成后，先核查两地 JOB_HASH 重叠，再汇总分子和分母、重算企业分布；不能简单平均两地比例。本批文件并非随机样本，暂不外推全库。
4. 职业和 AI 暴露分层尚缺经核验的职业映射，不能宣称已回答“是否集中在最关心的职业”。企业层面也不能凭事后排名认定其事前研究相关性。
5. 本轮已经完成总体日期风险统计与分组汇总；广告观察跨度分位数尚未交付。正文历史语义、职业映射及后续学历/经验/技能提取仍未完成。
