## 修复了什么，为什么没有重做旧广告

1. 默认 Python 缺 Parquet 依赖且没有 pip；在独立目录安装了官方 SHA 核验的 PyArrow 19.0.1，不修改全局环境、不创建新 VM。
2. 证据检查此前用尽 300 秒工程窗口；在新 run002 延续原游标、保留旧运行时间与所有保护，新增窗口最多 300 秒，实际约 172.5 秒，未重置金融预算。
3. 来源映射初版误以为原 Description 与筛选后的 canonical-USA 中间文件应有相同 SHA。查原 producer 代码及一个缓存回执后纠正了阶段对应；新版独立落盘，旧失败版本保留。这是修执行代码，不是放宽研究验收。
4. 一次控制模板语法错误在执行前失败；之后报告超出 RunCommand 输出容量，从已保存文件经私有 Blob 取回并核验，没有为取回报告重复执行安装或统计。
