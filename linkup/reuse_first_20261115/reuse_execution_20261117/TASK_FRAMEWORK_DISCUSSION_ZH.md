# 任务框架对齐备忘：讨论，不是新增测量或模型协议

日期：2026-11-17。用户在既有Azure落表运行期间询问任务模型与现有研究的关系。

## 现有研究问题不缩减

传统软件与生成式AI的扩散，如何改变岗位机会、工作内容和所需经历的组合？这些变化又对应哪些背景劳动者的进入、留任与转岗？

保留A机会重新分配、B经历重新组合、C工作职责演变、D人员进入路径、E早期计算机化对比。LinkUp刻画企业表达的劳动需求，Revelio在实际交付后刻画人员经历与流动；不假造广告—员工的直接录用对应。

## 可检验的组织主线

“AI、任务重组与职业进入机会：新机会是否向具有可迁移经验的劳动者开放？”是与既有议程兼容的论文组织建议，不是本轮已检验的结论。

- 降低门槛假说：AI承担部分专业执行任务，使一般经验、相邻任务经历或判断协调能力可以替代一部分行业/工具特定经验。
- 提高门槛假说：执行任务自动化后，剩余判断、核验、例外处理和责任承担提高领域知识与经验要求。
- 需要检验哪些岗位、哪些经历背景对应哪一种机制；新任务不必然对新人或跨界者开放。

## 与任务模型的映射及边界

A/C组织劳动需求与任务变化；B/D研究谁具备进入新组合的条件及谁真正进入。净广告变化本身不能分解替代、生产率与新任务效应，新措辞不等于新任务创造，职业份额上升不等于绝对机会增加。

平台降低学习、匹配或派单摩擦，是值得研究的扩展假说；把更多人匹配到既有任务不等于创造新任务。平台可能帮助新任务吸收劳动，也可能重新分配既有订单。要证明平台机制，需要其采用时点、培训/派单/交易/收入等数据及可信对照，不能仅用LinkUp/Revelio断言。

CREATED继续作为首次观察岗位发布时间代理；前后变化不自动等于AI因果效应，AI提及不等于实际采用。岗位广告不等于实际就业。完整宏观三效应分解与平台因果评估不是本轮新增前置。

## 理论结论不能提前当作实证结论

“生产率效应＋复归效应大于替代效应时净就业增长”可作直观组织，但不是把招聘广告数直接代入的可估计恒等式。任务份额、劳动需求、均衡工资、产品需求弹性、劳动供给与调整摩擦需要区分；短期净效应不由框架无条件保证为负。用户举例的岗位减少与成本降幅是说明场景，不是本项目实测值。当前数据首先研究可观察的招聘需求与人员流动，不将其冒充就业总量分解。
