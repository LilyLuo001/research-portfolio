## 比较一：GenAI使用与传统软件使用广告，经验组合是否不同

最终可明确归入两组的广告分别为71条、271条。GenAI组允许同时使用传统软件；主动开发／实施AI、预测型AI混合及角色不确定的广告不进入这个对比。另有222条广告的技术分类不确定（按样本计27.8%，设计加权约27.3%）；这些广告的潜在影响不在下表的未知经验界限中。

有4个职业大类同时满足每组至少5条样本的冻结门槛（代码11、13、15、17）。共同覆盖范围包含57条GenAI使用广告和247条传统软件使用广告。下表是这一范围内的设计加权描述；两组职业构成并未进一步标准化，不能称为相同企业、相同细分岗位的控制后结果。

| 明确表述的经验维度 | GenAI使用组 | 传统软件使用组 | 差异：百分点，95%设计区间 | 两组已定义覆盖率 |
| --- | ---: | ---: | ---: | ---: |
| 一般工作经验 | 32.1% | 16.5% | +15.6 [2.3, 28.9] | 98.0% / 94.0% |
| 职业／任务经验 | 93.2% | 87.7% | +5.4 [-2.5, 13.4] | 94.1% / 95.3% |
| 行业／领域经验 | 72.9% | 62.0% | +10.9 [-2.3, 24.2] | 98.0% / 96.6% |
| 工具特定经验 | 87.1% | 64.2% | **+22.9 [12.1, 33.7]** | 96.1% / 98.7% |

各百分比以该组已定义标签为分母。共同覆盖范围内，工具经验的记录未知界限分别为83.7%–87.6%和63.3%–64.6%；完整分母和其他维度界限见[T6](results/T6_SENSITIVITY_AND_BOUNDS.csv)。这些界限仅改变已记录的未知经验标签，不涵盖未发现的模型错误、技术组别误分或被排除广告。

**本轮最稳定的线索是工具经验措辞的共现差异。** 在全部抽中职业的两组对比中，工具经验差异也为正（+26.1个百分点，设计区间16.3–35.9）。一般经验的结果则随范围变化：全部抽中职业为+9.4个百分点，区间-1.9–20.8，不能概括为已经证实“AI岗位普遍更资深”。行业经验的幅度对复核处理尤其敏感。

这回答的是当前所见广告怎样表达要求。技术使用组本身也来自同一段正文，工具经验共现可能包含技术分组与经验措辞的联系；不能据此认定技术造成经验门槛提高或降低。

## 比较二：欢迎初入职场者的措辞，是否与当前责任并存

这里直接看所有技术类别，避免只保留能进入软件／GenAI对比的广告。宽定义包括明确经验豁免或欢迎毕业生措辞；某一类经验被豁免，并不等于整份职位完全不需要经验。因此同时报告更窄的明确欢迎毕业生定义。

| 当前被招聘者的职责 | 经验豁免或毕业生措辞：54条 | 仅明确毕业生措辞：33条 |
| --- | ---: | ---: |
| 独立判断／审核验证 | 40.2% | 33.5% |
| 客户责任 | 6.8% | 2.2% |
| 人员监督 | 4.9% | 0.0%（样本未见） |
| 培训／指导他人 | 13.3% | 4.0% |
| 至少一种上述职责 | **50.3%** | **42.6%** |

数字为有对应职责确定标签者中的加权比例，不是54条或33条中的简单比例。“至少一种”两列各有5条职责未知，95%设计区间分别为30.0%–70.6%和12.3%–72.9%，记录未知界限分别为47.0%–53.6%和35.8%–51.7%。明确毕业生样本较少，区间很宽。零检出及其退化的线性化零区间不能被解释为总体比例确定为零。

宽定义的加权广告质量为254.3，明确毕业生定义为103.6；另有11.8的加权质量因初级措辞本身未知而未进入这两个分母。上述职责未知界限不覆盖这部分成员资格不确定性。

**可以说欢迎毕业生的措辞与判断、客户责任或指导职责确实能同时出现；不能说这些岗位已经发生历史性的“seniorization”。** 只有当前被招聘者的职责计为正；对申请人既往能力、别的员工、雇主一般培养计划的描述，不计为当前职责。比例也不能替代实际入职资格或录用结果。

这些职责线索本身也不等于“资深岗位”：例如初级工程师正常承担的检查、测试和设计评审，也可能满足已冻结的判断／验证定义。它们证明职责内容可以与初级措辞并存，不能独自证明岗位级别提高。

## 复核究竟改变了什么

为避免拿不同样本比较，修正前后都使用同一800条广告、同一分析代码和权重。“前”是本次719个主审正文；“后”增加40个裁决，并把其余观察到的复核冲突置为未知。它不是最早的全库规则提取表，也不是准确率评估。

| 共同职业大类内经验差异 | 主审结果 | 最终结果 |
| --- | ---: | ---: |
| 一般工作经验 | +11.6个百分点 | +15.6个百分点 |
| 职业／任务经验 | +5.9个百分点 | +5.4个百分点 |
| 行业／领域经验 | +2.8个百分点 | +10.9个百分点 |
| 工具特定经验 | +24.4个百分点 | +22.9个百分点 |

工具经验方向和量级基本保留；行业经验不能被称为稳定结论。技术对比的组员也发生了变化：GenAI使用84→71条，传统软件286→271条，因此差值变化同时包含分类、成员组成和未知处理，不全是“标签纠错收益”。

另一个重要结果是：明确毕业生组“至少一种职责”的已定义比例从35.8%升至42.6%，**正例的加权分子37.0没有增加**。变化来自5条冲突记录退出已定义分母；其加权分母由103.6变为87.0。宽定义47.0%→50.3%也是同样原因。因此不能把这个上升解释成新发现了更多高级职责。

## 一次性裁决与后续边界

本轮按既定停止标准结项：两项核心比较、证据连接、正确分母、未知处理和修正影响均已交付。**不自动重开全库提取，不用这800条的判断批量覆盖未审阅广告。** 当前结果适合作为论文的测量方法、探索性描述和可复现附录；工具经验差异与毕业生／职责共现是可保留的研究线索。

尚不能作出的结论保持明确：144/153个复核正文存在某类签名差异，不是94%的错误率；AI与AI之间的一致也不构成人工金标准。抽样区间不包含语义错误，未审阅记录可能仍有类似错误。当前技术对比不是历史计算机化与AI扩散的因果比较。

供应商已说明 `JOB_HASH` 由URL生成，同一URL的description可能更新；不同年份出现不同hash也不足以证明旧正文版本被保存。Records的首次／末次观察日期可以用于广告生命期诊断，不能自动当作正文版本日期。没有历史文本版本就不报告“过去岗位要求被改写”的时间变化。

Revelio Individual尚未取得，本轮没有构造真实劳动者经历、进入概率或人员流动结果。接下来可直接把本次已冻结的表图写入数据与测量部分；历史和劳动者结论等相应数据具备后另立分析任务，不再作为本轮交付的等待条件。
