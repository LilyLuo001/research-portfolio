# D43：从反复整体验收转为分字段、可续跑的候选生产

## 本轮裁决

保留原研究主线、原始语料、固定一万条样本及 T1–T6。结束“所有模型、全部字段、全部引文完全一致才放行”的做法。首批真实正文已经产出候选结果，局部错误和歧义有独立状态，不再拖住整个样本。

这不是降低真实准确性的要求，而是把三个问题分开：数据是否正确绑定；经济概念是否有明确证据；剩余误差是否允许得出论文结论。第一项可以机械验收；第二项可以逐字段复核和保留未知；第三项不能仅凭模型相互同意来保证。

## 文献给出的规范及本项目的取舍

- Grimmer 与 Stewart 的 Text as Data 强调针对具体研究对象验证，并检查类别错误，而非寻找放之四海而皆准的准确率门槛。[原文](https://web.stanford.edu/~jgrimmer/tad2.pdf)
- Ludwig、Mullainathan 与 Rambachan 区分生成标签和利用标签估计经济关系。标签有误并非自动使项目不可做，但下游估计需要可信的验证测量或清楚的误差处理。[原文](https://www.nber.org/papers/w33344)
- GABRIEL 的测量研究分别检查构念、外部证据及提示稳健性；“两个模型同意”不能涵盖这些问题。[原文](https://www.nber.org/papers/w34834)
- Hansen 提出没有外部基准时的回译与分离检验，但这是有前提的新工作论文方法。本项目没有执行整套方法，不借用它宣称已经通过无人工验证。[原文](https://www.federalreserve.gov/econres/feds/files/2026020pap.pdf)

因此，按字段放行、固定批次、有限复核、一次修正和保留未知，是本项目为成本与研究用途做出的执行裁决。24/128 的批量、6/16 的随机复核量，以及系统错误的暂停规则，均不是文献规定的普遍标准。

引文编码修正单独记录。主读者两次编码修正之前的完整字节文件没有独立保存；已据逐字段日志重建首次语义内容，并明确标为重建文件，不假称原始字节备份。复核者的 ampersand 引文错误也保留在原始结果中。语义裁决层与所有主、复核结果分开保存。

## 从现在起的执行标准

| 情况 | 处理 |
|---|---|
| 源文、ID、哈希、顺序错误 | 隔离受影响批次，解决绑定问题后再用 |
| 有明确原文支持的核心字段 | 保存候选值和证据，进入已完成队列 |
| 一处歧义或缺失 | 该字段为空并保留原因，其他字段继续 |
| 年限含糊，但经验要求本身明确 | 保留经验指标，只将年限隔离 |
| 同类明确经济误分类在独立文本中重复 | 暂停相关字段或组别，限定一次修正；不重开全库 |
| 模型详略不同、JSON并非完全一致 | 按实际研究指标比较，不自动否决整条 |
| 同一字段一次修正后仍不可靠 | 降级该字段，不无限更换提示重试 |

后续逻辑批次为128篇独立正文；每批固定随机复核16篇，另加至多8篇被规则触发的疑难项。抽查包括“未提及”，以发现漏报。这只是运行与诊断安排，不足以认证某个总体准确率。已完成的提取不重跑，代码检查与裁决层可独立更新。

模型分工：Sol/medium 主提取和有限独立复核；Luna 做确定性计数、清单与发布；根模型处理构念边界、重大争议和最终验收。此次沿用的独立复核执行者为 Sol/high，限于十二篇。不会再让两个模型全量重复标注，也不会因较弱读者单独出错而否决全部结果。

## 规模与主张边界

首批候选生产已经完成；7,635篇全量无人值守推理尚未启动。当前实际执行通道是会话内委派模型；没有配置好的付费API，旧本地8B CPU路线也没有证明可在可接受时间和卡时内完成。清单就绪不等于后台正在推理。后续需要区分吞吐通道问题与测量放行问题，不再为了寻找一个完美提示反复冻结所有工作。

本批仅覆盖一般经验、职业任务经验、行业领域经验三个核心对象；工具经验与技术角色分类仍为之前的候选状态。本批不构成原完整四类经验体系的全面验收。

候选测量可以继续生产，论文结论需另行判断。未知不能删掉或当作零；按组别报告未知比例，并在完整样本上计算保留原分母的敏感性区间。这些区间只处理未决标签，不保证已决定标签没有共同错误。岗位首次观察时间也不能证明当前正文的历史有效日期。上述边界不因本轮验收改变。
