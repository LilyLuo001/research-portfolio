# Historical continuous production record

This directory preserves public source and run receipts from the 2026-10-08
continuous-production staging attempt. It is superseded by the D46 cloud-only
execution policy: new data processing and inference must run as scheduled
cloud/cluster jobs, with local work limited to control-plane activities.

The recorded counts and statuses are historical receipt values. They are not
current background and do not constitute a new cloud inference result.
