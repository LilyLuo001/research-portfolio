# D52：复用规则结果，预算一次联合语境判读

本轮交付是待判输入、变量使用边界和可审核预算，不是新一轮语义标签。D51 的 7,635 篇唯一正文及其 10,000 条样本映射保持冻结。此规模是现有研究样本，不是 LinkUp 全库。

## 为什么不继续改关键词

D51 的逐篇诊断发现，最低年限的字面数值可以正确，而“总工作经验必须、行业经验优先”的关系仍会被错误合并。软件名称旁边的“开发”也可能指开发报表，而不是开发软件。没有 review 标记的记录同样可能存在这些错误。因此只复核报错记录会留下系统性漏检。

规则层继续提供可追溯数字、引文和检索入口。语境层只解决研究需要的关系：经验对象、要求强度、替代条件、申请者资格，以及技术角色和岗位责任。不得把此层改名为已验证指标。

## 两条预算路径的含义

- A：宽检索提取经验相关上下文，合并重叠窗口；长行、跨行替代关系和高覆盖率退回全文。没有锚点的记录保留为未知。该方案只处理经验与资格，不能回答整份广告的任务构成问题。
- B：对全部唯一正文做一次联合判读，同时输出经验、资格、技术角色和任务责任。使用现成标准化正文，不重新抓取、不重复运行规则提取。
- A+B：说明先做局部再补全文造成的重复成本，不作为默认方案。

A 和 B 的研究覆盖不同，不能只按价格选择。如果任务责任与经验组合同时是本轮研究核心，应优先考虑一次 B，而不是把 A 包装成完整分析。正式选择以实际字符量和成本表作一次裁决。

## 必须保留的质量门槛

未来若具备模型服务，只沿用固定 eval80 做有限验收，不另起开发样本循环。检查证据存在、要求对象与强度、资格替代、针对谁的责任、未知值处理；分组报告问题。AI 复核不是人工金标准。未解决的复杂条件保持未知，不为得到完整表格强制二分。提示词/schema 本轮仅做代码与定义审查，尚未被模型实跑验证。

## 预算边界

价格核对日为 2026-10-08；使用 GPT-6 Astra Standard 和 Batch 的官方短上下文价格，不假设缓存优惠。每次请求包括指令、schema、正文及必要的窗口坐标。UTF-8 字节除以 5、4、3 仅为规划估算，不是实际 tokenizer，也不是严格上下界。输出预算包括隐藏推理，1,024/4,096/8,192/25,000 的上限情景不等于每篇实际消耗，也不保证答案完整。重复请求、额外审计和税费不在基础总额中。未发起模型 API 调用。
