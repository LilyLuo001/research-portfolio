## L3 状态

**L3 blocked。** 本地的“batch”仅证明计算集群上的确定性分片能力，不能替代外部模型批量调用通道。没有可核验的模型路由、数据许可范围、实际模型／版本／参数和预算上限前，不启动正式文本提取，也不以对话窗口处理约四万条正文。

## 可准备的开发合同（不执行调用）

在通道到位前，可冻结以下非秘密输入：

1. L1 的逐条样本 ID、层、入样概率、开发／评价／生产互斥标记，以及文本摘要去重规则。
2. L2 的 JSON schema：四类经历、技术类型与角色、`required/preferred/unknown`、数值绑定、替代分支、原文偏移和 `unknown` 状态。
3. 200 条开发／成本样本与独立 200 条评价样本的清单、排除规则和一次修改上限。
4. 分片重试、缓存、每条证据检查、失败率和约 2% 分层盲复核的收据字段。

正式调用开始前必须另有：已授权的实际入口、数据是否允许该处理方式的确认、预算上限、开发批真实成本／失败回执，以及冻结后的模型标识、参数、提示和 schema。该盘点没有验证这些条件。
