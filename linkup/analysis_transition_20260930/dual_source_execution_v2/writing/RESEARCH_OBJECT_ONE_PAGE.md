# 研究对象一页定义（G0）

共同问题是：计算机化与AI相关工作，分别怎样关联一般资历、相关经验和资格替代？不预设AI降低门槛，也不预设两类技术方向相反。

研究由两个独立模块组成：LinkUp 中旧 C1 候选框架内、按固定抽样与原始可比单元权重整理的公开招聘要求；以及（待取得数据后）Revelio Individual 中有观测职位进入事件及其进入前职业经历。两者不是同一批人，也不构成同一季度的联合样本，因此不把公开要求直接解释为实际录用概率。

经验分为四个对象：一般工作经历、明确职业或任务经历、行业/领域经历、具体工具经历。每个对象分别记录 prior experience、knowledge、proficiency、training/certification 或 unclear；学历替代工作年限只保留为有条件分支，不转成普遍的总工作年限。比较的分母必须随对象和条件明确：旧组使用原始合并可比单元权重，重分类组保留原纳入概率并报告权重损失；披露一般年限的广告只是条件描述分母，不代表全部广告。

现有CPS历史职业构成基准使用固定 Autor-Dorn RTI；软件岗位组则是保存文本中的工作类型参照。没有电脑使用字段，不能把它们当实际技术采用，也不能写成早期计算机革命的因果反事实。AI 相关角色须区分开发、实施、使用、评估/治理，不能由广告角色或当前描述推出技术扩散阶段。Revelio 尚未购买，R0 仅保留接口，R1–R3 与 J1 实证暂缓。

主估计对象是旧共同支持框内、按入样概率恢复并按固定单元权重汇总的招聘要求组间差异，属于描述性关联。
