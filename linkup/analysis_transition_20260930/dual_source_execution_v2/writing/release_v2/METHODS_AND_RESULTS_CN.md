# 方法与当前结果（release v2，2026-10-04）

本稿的两源设计把 LinkUp 的保存广告文本与 Revelio 的人员职业事件分别用于招聘要求和实际进入。但这不是当前的两源实证结果：Revelio Individual 尚未购买，R0 只有接口、输入契约与模板，未读取任何人员或履历数据；R1–R3 与 J1 均延后。今后若有数据，须先核验文件、schema、稳定人员ID和完整人员框；只有能区分持续观察与失访时，才可从期初风险集报告固定12个月转入率。

LinkUp 的实际完成项是抽样与有限开发准备。在冻结的69个共同支持单元，旧候选框含A组10,075、B组1,064,428，按A全取、B层内 `min(B,3A)` 抽得40,300个唯一键（A=10,075，B=30,225）。键唯一、层内计数与逆概率回构检查通过。因此，这一设计可描述旧候选框内、按原分层权重恢复的候选框事实；它不能代表所有AI岗位、所有广告、职位空缺、实际录用或劳动力市场总体。200条开发原文已取齐；evaluation 200键仍为暂定且未揭示，文本组排除与历史暴露溯源尚未完成。40,300是抽样键数，不是模型已处理记录：外部API调用与支出均为零，L3生产没有启动。

文本采用当前保存快照。`CREATED` 表示系统首次观察，不能当作保存正文的生效日期；有效的 `CREATED–LAST_CHECKED` 区间中37.49%跨季度、13.34%跨年。故本文不把某季度的保存文本解释为该季度入职者面对的同期需求，也不制造广告—人员同期匹配。现有CPS基准比较2004–2006与2023–2025两个窗口的职业构成和固定RTI，仅作描述背景，不衡量电脑采用，也不重建早期计算机化的因果过程。

开发测量在v1.1关闭前使用20条固定未用记录、两位独立AI读者，共40次新阅读；累计为80次独立阅读。结构核验通过，但语义门槛未通过：年限会被错误外推到同句工具，且“工作或培训”的preferred条件曾被遗漏。双读者的职业/任务年限签名13/20一致、技术类别—角色集合14/20一致；它们是AI辅助来源判读的比较，既非人工金标准也非准确率。每位读者在原B组10条中各发现2条AI候选，仅提示B不能称为已知非AI对照，不构成对照污染率或总体AI比例估计。故可发布覆盖、抽样、工程收据和旧候选敏感性诊断；不得把候选差异写成已验证的经验要求、AI招聘门槛、招聘概率或因果效应。

旧表中的一般经验是狭义显式对象候选，职业/任务经验为NA；行业和工具同样未获正式语义验收。预测型AI零值受申请人语境门控，不能读作没有需求。最终可用主结果仍依赖经验证的对象/年限/条件分支测量、锁定独立评估和可用批量通道；本波次不再修订提示词、扩展阅读或启动生产。

实际样本设计诊断进一步区分两种权重：逆纳入概率权重用于恢复各组候选框人数；原始合并单元权重用于令两组面向同一职业—地区—队列分布。B组逆概率权重约5.14–421.59，对应Kish值约9,393；比较标准化权重的Kish值为A约3,172、B约9,515。它们仅衡量权重集中，不能当作聚类后的有效样本量或统计功效。前三职业大类占共同支持框架约80.73%，最大单元占4.52%。保留原设计，不截断权重；样本25%/75%的组别比例也不能用来估计AI岗位占比。详见[设计诊断](../../analysis_design_v2/design_diagnostics.json)。
