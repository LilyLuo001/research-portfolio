# LinkUp 既有全库结果（T1–T6）

本目录交付现有全库的冻结、确定性规则命中结果：它不是新近验证的经验要求发生率、AI 的因果效应，也不是 40,300 条模型结果。三项已完成事实可直接引用。第一，T1 显示美国 `Records` 的 253,210,047 行中，204,774,035 个经全局唯一键审计的规范广告可反向连接，覆盖率 80.87%，即当前快照的工程连接范围。第二，T4 的 204,773,879 个有效 `CREATED–LAST_CHECKED` 区间中，37.49% 跨季度、13.34% 跨年，1.68% 跨 2022-11-30、1.66% 跨 2023-01-01；保存正文不能机械归入首次观察期。第三，旧 C1 候选组主规格在 69 个共同支持单元、9 个职业大类内的标准化差异为：一般工作经验 +5.706 个百分点、行业／领域经验 −2.690 个百分点、特定工具经验 −17.342 个百分点。

T6 的全套敏感性包含 `s3_single_quarter_closed`，而非仅四个展示规格：一般工作经验的标准化差异在 +4.823 至 +8.208 个百分点之间；行业／领域经验从原始差异 +2.081 个百分点转为标准化差异 −2.690 个百分点，表明候选规则组的差别会受到共同支持单元构成影响；特定工具在主规格为 −17.342 个百分点，且词表与传统软件定义词耦合，不能把该结果表述为“AI 使经验门槛更公平”。C2（develop）因共同支持过弱而取消，所有相关格均为 NA，绝不可填为 0；职业／任务经验未测量，同样为 NA。

这是一套可发布的现有全库结果交付，同时保留已知误测与覆盖限制。旧经验规则源于旧统计，尚未通过新版语义验收；日期是交付观察区间，不识别正文何时生效或修改；没有 Revelio Individual 实证，因而不能报告个人进入、转职或录用，也不能把候选词命中说成实际经历流行率或 AI 导致的招聘变化。

六张结果表的用途与相对路径见 [SIX_TABLES.md](SIX_TABLES.md)：T1 为覆盖与连接，T2 为候选经验率，T3 为技术共现，T4 为时间与集中度，T5 为主规格比较，T6 为敏感性与主张状态。
