# 可转发给 Dewey／LinkUp 的核实问题（草稿，尚未发送）

We are using the Dewey LinkUp Job Descriptions export with a dataset version dated September 6, 2026. We can join descriptions to Job Records by JOB_HASH. For historical research, could you clarify the following for this specific delivery?

1. Which text version is delivered for each JOB_HASH: the first observed text, the latest observed text, or another selection rule? Does the rule differ for active and closed postings?
2. Once a posting is marked deleted, is its retained description fixed? How are a reused URL or a reappearing posting handled, including whether JOB_HASH is reused?
3. Does LAST_UPDATED respond to description changes specifically or to changes in any posting field? What does a missing LAST_UPDATED mean?
4. Can you provide a small example linking JOB_HASH, two dated observations and their text, or a description of how to obtain historical daily files/monthly snapshots through our existing academic access?

We do not need a new bulk download to answer these questions. A delivery-specific explanation and a small dated example would help determine whether we can interpret text as historical requirements or only as the delivered version linked to each first-observed cohort.
