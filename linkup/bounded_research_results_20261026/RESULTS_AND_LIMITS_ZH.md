# LinkUp 招聘要求的固定范围研究结果

日期：2026年10月26日。性质：固定范围的中期研究交付，不是论文终稿或全库精细语义生产完成声明。

现有证据支持描述明确初级资格与当前岗位职责的共现，也支持在参考已知范围内比较不同技术措辞对应的经验组合。但在允许技术组成员和结果未知后，四类经验差异的方向都没有在完整候选母框内确定。现阶段不能据此声称AI提高了经验门槛、减少初级招聘，或导致岗位随时间高级化。

## 研究对象与估计口径

参考数据是既有Batch069最终判断所连接的完整fixed10k，即10,000条广告；隔离、未知和历史暴露成员按原规则保留。14个隔离上下文对应16条广告，不从广告分母删除；1,002份含审后未知的上下文按字段保留，不等于1,002条广告全部不可用。接受状态若按经验对象字段族给出，该族未知会同时影响四类经验，不能将其中某类当作已知未提及。判断来自Pro模型实际阅读，不是独立人工真值。已完成的2,736份年限关系补判侧表单独存档，没有假定它们已进入下面的统计。

主结果复用10月24日已经完成的设计校正，目标是原69单元、1,157,573条广告的技术筛选候选母框，不是全美招聘市场或全部2.048亿条广告。使用原纳入概率和逆概率设计权重；不套用Formal800的第三阶段w3权重。GenAI组允许同时使用传统软件；软件比较组为传统软件使用且无active-AI的既定组别。它们是广告文本分组，不是企业技术采用或处理状态。

职业构成固定为SOC大类11、13、15、17各占0.25。点估计描述各指标参考结果已知的范围；不同字段的已知分母可能不同，不能将这些比例当作同一固定完整人群的全面画像。必需大类缺少已知分母时保留不可得，不删去该类后重新归一化。

下列两种不确定性分开呈现：

- **近似95%设计区间**：反映既有抽样设计下的抽样不确定性，依赖独立加盐哈希排序可视作可交换随机抽样等原有假设；不包含Pro共同误读。
- **完整目标未知界限**：既有保守敏感性包络，允许未确定的组成员与结果变化。它不是置信区间，也不是经过证明的锐界；不将未知填成零。它本身没有叠加抽样不确定性，其下端不能称为95%置信下界。

## 软件与GenAI广告中的经验组合

表内单位均为百分点，方向为GenAI组减软件比较组。沿用四大类各0.25的构成。

| 经验类型 | 参考已知范围内差异 | 近似95%设计区间 | 完整目标未知界限 |
| --- | ---: | ---: | ---: |
| 一般工作经验 | −0.38 | −4.98至+4.22 | −16.71至+84.43 |
| 职业／任务经验 | +9.96 | +5.90至+14.03 | −71.17至+21.60 |
| 行业／领域经验 | −1.70 | −11.49至+8.09 | −50.47至+45.82 |
| 工具特定经验 | +23.42 | +15.35至+31.50 | −54.70至+38.57 |

来源：[既有CORE_Q1](../design_correction_20261024/results/CORE_Q1.csv)，选择`GenAI_minus_software_contrast`、`equal_0.25_major_standardization`。

**可以采用的解释**：在参考已知范围中，一般工作与行业经验没有明确方向差异；职业／任务与工具经验的差异为正。完整目标未知界限四项都包含零，因此这些结果不能建立完整候选母框中的方向性排序。“没有明确差异”也不等于证明两组相同。

一般工作经验的旧候选代理差异为+7.68个百分点，校正后为−0.38；工具经验从旧代理−16.60变为已知范围的+23.42。这说明粗代理结论对测量口径和参考校正敏感。差异包含定义与覆盖变化，不能全部叫作抽取错误，更不是历史上的经验要求变化。职业／任务经验在本次冻结的旧比较源中无兼容结果，所以+9.96是参考加权比较，不能称为旧结果纠错成功。

明确年限、必需／优先和替代分支继续引用既有T2逐条要求表。它们不构成上述经验出现率的可相加分解，也不支持把多条条件压成一个岗位最低年限。

## 初级资格与当前职责的共现

此处资格是广告明确出现应届毕业生或无经验者可进入的措辞，包含既有有条件与无条件情况；不是所有初级岗位，也不以junior标题或未提及经验代替资格。职责只包括广告岗位当前职责。

| 当前职责 | 参考已知范围内比例 | 近似95%设计区间 | 完整目标未知界限 |
| --- | ---: | ---: | ---: |
| 任一种已定义职责 | 51.08% | 34.22%至67.95% | 39.68%至63.37% |
| 独立判断 | 44.34% | 27.62%至61.05% | 34.55%至59.07% |
| 客户责任 | 8.65% | 1.13%至16.17% | 6.19%至34.34% |
| 人员监督 | 6.71% | −0.73%至14.14% | 3.11%至29.59% |
| 培训指导 | 14.04% | 4.75%至23.32% | 8.86%至34.69% |

来源：[既有CORE_Q2](../design_correction_20261024/results/CORE_Q2.csv)，选择`domain_proportion`、`all_technology`、`graduate_or_noexperience`、`equal_0.25_major_standardization`。

这些职责可以重叠，不能相加。人员监督的已知阳性仅4条，维持探索性描述；负的近似区间下限是原正态近似的结果，不代表负概率。稀疏或零阳性单元的零标准误不能作为确定不存在的证据。

**可以采用的解释**：在这一受限对象与参考标准下，明确初级资格可与当前岗位职责共现。原合并口径的已知样本为186条，其中110条至少有一种职责，原合并设计加权比例为51.42%。表内51.08%另按四个大类分别计算比例后等权，不是110除以186，也不存在一个可直接相除的统一计数分母。仅保留无条件资格时，四大类等权点值为47.72%，近似设计区间25.27%至70.18%，未知界限33.95%至68.17%；这仍不是所有初级岗位的市场比例。

**尚不能采用的解释**：既有职责schema没有必需／优先字段，不能把职责共现解释为硬性准入门槛，也不能从经验条款的强度跨接成职责强度。当前文本的共现不证明岗位已经高级化或AI造成这些职责。GenAI资格与职责分析的已知资格域仅14条广告，且一个必需职业大类没有已知分母，标准化两组差异不可得；不删除该类来制造比较。

本次冻结旧比较源缺少兼容的资格与职责比较项。因此本题是参考数据的设计加权估计，不是旧规则关系纠错后的效果展示。

## 结论采用范围

| 问题或主张 | 当前裁决 |
| --- | --- |
| 明确初级资格是否能与独立判断、客户责任或监督指导共现 | 可作限定范围的描述；职责不等于必需准入要求 |
| 已知参考范围中，GenAI与软件广告的四类经验组合是否不同 | 可报告上述点值、区间和不同字段分母；不能外推到未知部分 |
| 完整候选母框中，哪一组经验要求更高 | 当前四项方向都未确定 |
| 年限、必需／优先和替代条件 | 可引用现有逐条描述；不生成唯一岗位最低经验，不推断尚未建立的跨条款关系 |
| AI导致初级岗位减少或岗位高级化 | 当前不能回答；没有相应的历史正文和因果证据 |
| 计算机化与AI两个历史扩散阶段是否方向不同 | 当前文本分组不足以回答，不能用传统软件措辞替代完整历史计算机化比较 |
| 全美招聘市场或全部两亿条广告的精细语义结论 | 不获支持；全库精细语义生产仍未完成 |

日期进一步限制历史解释：JOB_HASH按URL生成，同URL正文可能更新。Records的首次观察日期不能把当前保存正文自动变成该年份的招聘要求。fixed10k现有精确日期、公司与标题连接不足的项目，仍按既有T4不可得处理。
