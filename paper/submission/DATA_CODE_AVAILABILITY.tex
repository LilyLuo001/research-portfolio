\section*{Data and Code Availability}

The labor-market microdata are from IPUMS CPS, which harmonizes the public-use Current Population Survey. Researchers may obtain the data directly from IPUMS subject to its registration and terms of use; the microdata are not redistributed with this package. Occupational AI-exposure inputs originate with the cited AIOE and GPT-exposure studies. Public source files are vendored only when their licenses permit; otherwise the replication manifest records the provider, version, retrieval information, and checksum. Occupational crosswalks come from official Census and Bureau of Labor Statistics sources.

The replication archive contains code for harmonization, treatment construction, frozen analysis, tables, figures, and validation receipts. The design-freeze and confirmatory-results Git references are recorded in the archive. Machine-specific paths, host information, usernames, and credentials are excluded. Because access to IPUMS CPS requires user registration, reproducing results from raw microdata requires the replicator to obtain an authorized extract matching the documented specification.
