## 1. Estimating equation

Per §6, stacked over event waves.

**v2.0 主规格**(股票 i、盈余事件 e、期限 h;对每个 h 分别估计):

```
Speed^h_{i,e} = β_h · (ConvExp_{i,w} × Post_{e,w} × |Surprise_{i,e}|)
              + (全部低阶交互项)
              + γ'X_{i,e} + α_i + δ_{industry×year-quarter} + ε_{i,e}
```

主表用 `Tier^k`(剂量三分位,决策 V-3)替代连续 `ConvExp`;连续版进稳健性,
且凡作 ACRT 解释处须标注 strong parallel trends(决策 V-2)。

**v1.0 原方程(仍用于脊柱一/二/四的日频结果变量)**:

```
Y_{i,t} = Σ_k β_k · (Post_{e,t} × Tier^k_{i,e}) + γ'X_{i,t} + α_i + δ_{t×industry} + ε_{i,t}
```

| term | definition |
|---|---|
| `i, t` | stock, quarter |
| `e` | event wave |
| `Post_{e,t}` | 1 for quarters at/after wave `e`'s **announcement** date (see §5) |
| `Tier^k_{i,e}` | **dose tercile** indicator, k ∈ {low, mid, high} — see below |
| `X_{i,t}` | controls, §6 threats T3/T4: concurrent Russell add/drop + bandwidth distance, fund net flow, stock-level flow-induced trading (Lou 2012 style) |
| `α_i` | stock fixed effect |
| `δ_{t×industry}` | quarter × industry fixed effect |

**Dose enters as terciles, not continuously** (decision V-3). Terciles are cut on
`conv_exp` **within the treated set only**, at the wave level, using
pre-announcement holdings; zero-dose stocks are the control group and are never
assigned a tier. Cut points are frozen once and recorded in the blueprint's
lineage JSON before estimation.

Two independent facts force this, neither of them a preference:

1. `shared/econlib` has **no continuous-dose estimator** — `callaway_santanna`,
   `stacked_did` and `twfe_did` are all binary/staggered on `first_treat`. A
   continuous primary spec is not implementable today, WRDS or not.
   (`ops/briefs/SH-econlib-continuous-dose.md` specs the fix.)
2. The ≥1% tier holds **24 treated stocks against a floor of 33** — the fine dose
   grid is underpowered whichever estimator exists.

Continuous dose-response moves to robustness (§7).

**Never report TWFE alone** (§6: 绝不单独报 TWFE). Where a TWFE number appears at
all it is labelled a reference quantity, with the note that its implicit weights
differ from the treated dose distribution.

## 2. Estimator 1 (primary) — stacked DiD with clean controls

### Clean-control construction, per wave

For each wave `e` with announcement date `a_e`:

1. **Event window**: quarters `[a_e − 8, a_e + 8]` (§7's pre_quarters, matching the
   pre-trend requirement of 4–8 quarters in §8 item 2).
2. **Treated**: stocks with `conv_exp_{i,e} ≥ 0.005` — the 0.5% line Gate 2 was
   read on. Assigned to a tier as in §1.
3. **Controls — the clean-control rule**: a stock enters wave `e`'s control set
   only if it is
   - not treated in wave `e` (`conv_exp = 0`), **and**
   - **not already treated in any earlier wave** within its own window
     (§6: 禁止 already-treated 进对照), **and**
   - not treated in any wave falling inside `[a_e − 8, a_e + 8]` — i.e. not
     *not-yet-treated-but-soon* either. Forbidding only already-treated leaves
     future-treated units in the control group, which is the same contamination
     running the other way.
4. Each wave's stack is a **separate dataset with its own fixed effects**; the
   stacks are then pooled with wave-specific FE. A stock may appear in several
   stacks and is clustered on accordingly (§4).
5. **Weights**: waves enter **unweighted by default**, so W002 does not
   additionally dominate through weighting on top of dominating through size.
   Wave-size weighting is reported as a robustness variant, not the default.
   This is a deliberate departure from the usual size weighting and must be
   flagged for the channel-B diff.

### Transition-window exclusion

§6 threat T2: announcement→effective is typically 2–6 months and holdings are
public, so arbitrageurs can position early. **Quarters strictly between the
announcement and effective dates are dropped from the main estimate** and retained
only for the event-study figure.

## 3. Estimator 2/3 (robustness) — Callaway–Sant'Anna and Sun–Abraham

Both are reported as robustness, never as the primary (§6).

**The assumption difference must be stated in the paper, not just here** (§T5:
明确说明各自的原假设差异):

| | identifying assumption | control group | what it buys |
|---|---|---|---|
| **Stacked DiD** | parallel trends within each wave's window | clean controls per wave | transparent, matches the event structure, no negative weights by construction |
| **Callaway–Sant'Anna** | parallel trends conditional on covariates, by cohort | never-treated **or** not-yet-treated (report both) | group-time ATTs immune to the forbidden-comparison problem |
| **Sun–Abraham** | no anticipation + parallel trends | cohort-interacted | decomposes a contaminated event-study coefficient into clean cohort-time effects |

With dose as terciles, all three run on a binary treated indicator **within
tier** — this is what makes them implementable with the current econlib.

**Do not run CS or SA on continuous dose** until the econlib estimator exists.
Feeding a continuous dose to a binary-adoption estimator silently redefines the
estimand, and nothing in the output would show it.

## 4. Inference — three sets, all reported

§6 requires three, with randomization inference **in the main table**
(随机化推断是少事件设计的生命线,放主表). Given §0's concentration this is the most
load-bearing section of the blueprint.

### (i) Two-way clustering — wave × industry

Cluster dimensions: event wave and industry. **Report the effective number of
clusters next to every standard error.** With ten treated waves and one carrying
92.8% of mass, the effective count is far below the nominal one, and a reader
must be able to see that without recomputing it.

> **v2.0 附注 — 为什么股票层聚类不够。**
> 计划 §6.3 的 T8:一个 DFA 基金持有上千只股票,这些股票的残差**不独立**,
> 因为它们共享同一个基金层冲击(申赎、流量、篮子再平衡)。
> 按股票聚类默认这些股票是独立簇 —— 在本设计里这个假设明显为假,
> 会把标准误压得过低。
>
> 因此聚类层级**必须上调到能吸收基金层共同冲击的粒度**:
> 主表 `wave × industry`;并在稳健性中报告
> **发起人/家族层**单向聚类(簇数为个位数,故必须配合 (ii) 的 WCR)。
>
> 分析单位变成 股票 × 盈余事件 后,还多了一层**同一股票的多个盈余事件之间**
> 的序列相关。若不按股票吸收,重复测量会再次压低标准误。
> **方案**:主表 `wave × industry` 双向聚类 **+ 股票层固定效应 α_i**(已在方程中),
> 稳健性另报 `stock × wave` 双向聚类。三者若给出实质不同的结论,以最保守者为准
> 并在正文说明。

`econlib.wildboot.wild_cluster_bootstrap` exists for the next item; the two-way
cluster variance itself is a `shared/` addition if not already present — check
before implementing, and do not re-implement it inside `p1/`.

### (ii) Wild cluster bootstrap

- **Impose the null** (restricted/WCR bootstrap): estimate under `H₀: β_k = 0`,
  resample residuals with Rademacher weights at the **wave** level, re-estimate.
  Unrestricted bootstrap is known to behave badly with few clusters; imposing the
  null is the whole point.
- Rademacher weights, 9,999 replications, seed recorded.
- **Known limitation, stated in the paper:** with one dominant cluster, even WCR
  is unreliable. It is reported for completeness, not as the decisive number.

### (iii) Randomization inference — the main-table number

Two permutation schemes, both reported, because with §0's concentration they are
**not** equally informative:

| scheme | unit permuted | reps | status |
|---|---|---|---|
| **Conversion-date reshuffle** | wave effective dates, redrawn within the sample period | 1,000 | **near-degenerate — see below** |
| **Fund substitution** | converted funds replaced by characteristic-matched non-converted funds (size, BM, momentum, pre-conversion ETF ownership, Amihud — §5's matching set) | 1,000 | **the informative one** |

**The date-reshuffle scheme is close to degenerate here, and the blueprint says so
in advance.** Permuting conversion dates when 92.8% of treated mass sits in one
wave is effectively permuting the date of a single event: the permutation
distribution is driven by where that one wave lands, not by ten independent
draws. It is reported, with its effective support stated, and it is **not** the
number the paper leans on.

Fund substitution keeps the treated holdings structure and re-randomises *which*
funds converted, so it retains variation the design actually has. It is the
main-table randomization-inference p-value.

**Pre-committed:** if the two schemes disagree in sign or cross conventional
significance in opposite directions, that disagreement is reported as a result,
not resolved by choosing one. Recording this now is what stops it from becoming a
choice later.

## 6. The DFA arm — binding pre-commitment (decision V-1)

The primary specification is the **pooled** design over all treated waves. The
DFA dominance is reported **in the main text**, not a footnote.

**Both arms appear in the same main results table, always, whatever either
shows:**

| arm | treated stocks (≥0.5%) | powered? |
|---|---|---|
| Pooled (all waves) | 389 | yes |
| **Excluding DFA (W002)** | **36** | above the floor of 33, by 3 |

If the effect is present pooled and absent excluding DFA, **that is the reported
finding** — §10 outcome B — and it is not resolved by dropping the weaker arm.
The exclude-DFA arm is registered as underpowered *now*, precisely so it cannot
later be discarded for being underpowered.

Under decision V-6 (Option A, drop pure-international waves), `excl DFA + Option
A` = 28 stocks, **below the floor**. That combination is reported as underpowered
rather than suppressed.

## 7. Robustness grid (feeds T7)

Ordered as §8 orders it — by referee attack order.

1. **Exclude DFA / DFA only** — §8 item 1, and now the main-text arm above.
2. Three estimators (stacked / CS / SA) + dynamic event study, 4–8 pre-quarters.
3. Three inference sets, as §4.
4. **Dose: terciles (primary) / binary / continuous** — continuous *only* once the
   econlib estimator lands, and reported with **strong parallel trends** named in
   the table caption (decision V-2). Cross-tier comparisons under standard
   parallel trends are descriptive only: they carry selection bias by
   construction (Callaway/Goodman-Bacon/Sant'Anna, NBER w32117).
5. Exclude 2021Q2–Q3 (meme + Russell), exclude COVID, exclude price < $5.
6. Announcement-date vs effective-date `t = 0`; transition window in/out.
7. Controls: concurrent index reconstitution, fund net flow + FIT, short-sale
   constraint changes, contemporaneous ETF-ownership changes from 13F/N-PORT.
8. Outcome substitution: GNZ original measure / IPT / delay / peer-response.
9. Placebos: twin non-converted funds, fixed-income converters' equity noise
   holdings (should be null), already-heavily-ETF'd stocks (marginal effect
   should approach zero — itself a dose prediction).
