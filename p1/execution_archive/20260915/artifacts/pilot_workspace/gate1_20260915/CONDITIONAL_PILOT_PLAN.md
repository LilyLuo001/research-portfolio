## Stage C — dependence and inference feasibility

Build an economic-event-level map linking repeated issuer events, shared stocks, sponsor/package shocks and overlapping response dates at all horizons. Carry covariance across horizons and repeated stack use. Report counts and concentration by wave, sponsor, stock and date, connected components and dominant influence shares. Report full-model and leave-one-wave/sponsor sensitivity designs without selecting them by POST outcomes.

Graph components are not automatically effective sample size. A giant component blocks the proposed independent-component procedure, not every mathematically conceivable inference scheme. Conversely, nonnested multiway methods or bootstrap software do not establish validity with a few conversion shocks. Any alternative must have a defensible assignment/sampling model, finite-cluster checks and a precommitted validity criterion. Randomization inference requires a credible assignment mechanism, not arbitrary label shuffling.

Exit: a signed inference protocol whose operating characteristics can be tested under the actual design. If no credible protocol exists, HOLD_DESIGN/NO_GO for that target even with perfect quote coverage.
