### 3. 首先产出 ETF／篮子的经济量级和时序结果

固定共同 baseline 为锚点 -5 分钟。每个证券用相同规则取得 bid/ask/mid 和年龄，复用已修正的状态选择，保留无效状态和文件边界。没有更新不是自动失效；高龄报价与不确定连续性进入敏感性解释。

以简单累计收益构造固定权重股票部分：

`B(t) = sum_j w_j × [P_j(t) / P_j(baseline) - 1]`

`E(t) = P_SPY(t) / P_SPY(baseline) - 1`

权重为小数。B 的资产覆盖与 SPY 不完全相同的部分单独报告；未观察部分的收益不默认零。先画 E、B、E−B 和价差敏感性，再报告 0、+1、+5、+15、+30、+60 分钟。tracking discrepancy 包含真实基差、滞后权重、缺失资产与报价差异，不能把它全部称测量误差或套利利润。

主时序诊断固定使用 -5 至 +30 分钟的一分钟变动。对 lag `-5,-4,...,0,...,+5` 全部报告 `corr(ΔE(t), ΔB(t+lag))`，共同可用支持保持一致，并报告配对数；正 lag 表示 ETF 的变动更早。零方差或支持不足记不可计算，不能记零。给出完整相关曲线和最大相关 lag；这是短窗探索性描述，不是信息份额、总体显著性或因果估计。

用同样一分钟网格整体平移 30 秒、以及 ARCX 同样计算检验方向是否稳定。结果支持不了一分钟内的先后就报告同时／无法区分。不能把 bbo-1s 的采样频率当成新闻发生时间精度。补充 0 至 +30 分钟结果供识别窗口依赖，但不在两者中挑好看的主结果。

宽价差、高龄状态和缺失权重是否足以改变领先方向，应在图表中可见。对可能决定符号的高权重成分做有限敏感性，保留原主结果；不删除这些成分后再把新符号当“修复”的结论。

### 4. 隐含个股诊断与误差放大同步交付

对发行人 i，使用同一权重口径计算：

`R_rest(t) = sum_(j != i) w_j × r_j(t)`

`r_i_implied(t) = [E(t) − R_rest(t)] / w_i`

在同一已观察代理内，恒等式是：

`r_i_implied(t) − r_i(t) = [E(t) − B(t)] / w_i`

这说明两条曲线贴合和 residual 收敛并非独立机制证据。直接报告 1/w_i：XOM、UNH 大约会把组合端误差放大 70–85 倍，AAPL、MSFT 约 13–17 倍，以实际权重精确计算。

用真实报价跨价差区间推导 rest 篮子及隐含个股的区间；对无法观测的遗漏资产，展示“遗漏资产需要多大变动才能改写判断”的 break-even 情景，不能虚构置信界。没有数据支持的范围标为情景而非估计。不得用观察到的 E−B 反过来校准篮子使其贴合 SPY。

只有同一方向超出所观察的价差、网格、场所和权重缺口敏感性，才描述为本窗口的领先线索；其他窗口如实报告方向不稳定或无法分辨。主 ETF／篮子结果照常交付，不因为隐含个股诊断失败而冻结全轮。
