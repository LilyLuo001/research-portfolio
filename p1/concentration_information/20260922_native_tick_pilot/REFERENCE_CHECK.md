# Ernst 抽样参考核查及本轮判断

日期：2026-09-22。仅公开资料核查/方案准备，未执行新数据分析。

核对版本：[Ernst 2022-03-22 作者稿](https://terpconnect.umd.edu/~ternst/docs/Ernst_ETF.pdf)，数据段、同步匹配方法、表IV/V、附录H。并非完整复现。

- 样本实际为2015-08-01至2018-12-31、S&P500股票及552只符合条件的ETF；不是仅SPY/QQQ/板块ETF或前20股。权重是研究变量，不能以“只有大权重股才有机制”为由删除其余股票。
- 同步区间±20微秒，背景区间±1000至1200微秒；以长度比0.1扣除背景。超过1毫秒全部删除会破坏该背景估计。
- 原文有财报日指标与普通日横截面/时间变化，不支持“主要删除所有普通日”；不能把其结果归因于只保留高信号事件。
- 作者引用 Holden–Jacobsen 清洗并排除毫秒精度成交，但本轮未核实参考消息所称的全部09:30–16:00过滤、统一删除大宗交易、只留NBBO等实施细节。不能把推测写成作者规则。附录另有排除每秒前200毫秒的稳健性，属于周期交易诊断。

上述是出处核查。下列是我们自己的设计判断，不归于 Ernst：

1. 原生逐笔数据比一秒快照更适合验证近同步交易；这不保证观测精度、方向可识别或研究有新贡献。
2. 排序后用范围查询/双指针和聚合计数可避免全配对爆炸；不必先删除经济上关键的普通日或低权重股票。小样本选择用于工程可行性，不用于证明覆盖面。
3. 本轮新增日间窗口是明确的样本修订。原盘前盘后窗口保留用于旧发现的诊断。日间发现不能被称为旧公告后瞬时效应。
4. 大额成交不自动是垃圾，长时间没变化的有效报价不自动陈旧；应按具体源的交易条件/更正/状态字段处理。高价差是可观察特征，不预设为无用噪声。
5. Ernst 同向同步交易不同于典型反向篮子套利；即使测到同步峰，也仍需方向、背景率和后续报价证据。不能把同步配对直接写成同一账户交易。

数据语义依据：[Databento MBP-1](https://databento.com/docs/schemas-and-data-formats/mbp-1)、[时间戳规范](https://databento.com/docs/standards-and-conventions/common-fields-enums-types)、[XNAS映射](https://databento.com/docs/venues-and-datasets/xnas-itch)。MBP-1包括顶部盘口事件与交易；ts_event保留发布方时间，ts_recv是数据商接收时刻；side是否能识别主动方须按源验证。只有字段纳秒精度，不足以认证跨撮合系统时钟同步。

现有项目没有TAQ访问，不连接WRDS；先用Databento原生feed做可明确限定场所的试点。若实现只能得到普通同步事实，则它是方法验证，不是新论文贡献。
