## 2. 一次源适配，直接进入计算

输出简短SOURCE_FIELD_MAP：dataset/schema、时钟字段原始语义、历史分辨率、交易action、sequence/ID、方向可用性、更正/取消/拍卖标志、报价快照的前后语义。依据官方源文档和少量实际记录；缺字段保留UNKNOWN，不猜。

ts_event为主源事件轴；ts_recv为独立的接收轴敏感性，不叫SIP。保留纳秒整数，禁止float UNIX time或取整成毫秒。检查并报告时间戳堆积、同刻重复、非单调和质量flags。不能靠同步峰反推时钟偏移。原生文件接收顺序与事件顺序各自保存；构建接收轴报价时不能按event time泄露未来。

按来源识别真实成交；Trade/Fill等不能重复计量同一经济成交。更正/取消、非连续交易/拍卖等按源规则处理并给每步计数。不删除所有大额成交，不要求成交触发NBBO变化才保留，不把不同ID的同时间/同价/同量成交去重掉。普通挂单撤销属于报价状态更新，不是“垃圾成交”。

报价为空、crossed、零侧/undefined等明确处理。无新消息的live quote可以继续有效；文件边界/明确失效不能延续。显示价差及距最后报价事件的时间；仅有间隔快照时真实年龄仍UNKNOWN。

主动方向仅对有官方语义支持的记录用原生side。未知方向可补充用严格交易前可得midquote分类：成交高于mid记买、低于mid记卖；在mid/缺报价/同刻顺序不明时保持UNKNOWN，不自动tick-test填满。把原生方向与推断方向分别报告；不要将盘口bid/ask侧误作主动方。

## 3. 聚合计数，禁止笛卡尔积

按日期/场所/证券分区，排序后以双指针或searchsorted做有界范围计数。主程序不要创建N×M表或输出每一对成交。优先按买/卖/未知时间数组和前缀计数求各区间数量，复杂度约O(N log M)每组固定区间；分块并保留5毫秒时间重叠，按中心股票成交的所属块唯一计数。成交后60秒报价另用as-of索引，不把匹配窗口扩成60秒。

定义d=t_ETF−t_stock，d>0表示股票成交在前。保留±5毫秒的偏移直方图；主近同步区间[-20,+20)微秒，背景[-1200,-1000)与[1000,1200)微秒，长度比40/400=0.1：

    Excess_pairs = N_near − 0.1 × N_background

该20微秒是文献启发的描述区间，不假定2023年反应速度必大于20微秒。实际时钟分辨率或准确度不支持时照样报告计数/局限，不贴“物理上不可能相互反应”标签。只有独立历史latency/时钟证据支持才有资格解释物理同步。

另固定±100微秒与±1毫秒两档，仍用同背景并按宽度200/400、2000/400缩放；毫秒档背景临近主区间，标明其稳态背景假设。它们不是替换20微秒寻找结果。保留负excess，不截零。分别输出BB、SS、BS、SB及UNKNOWN，先无符号计数后分方向，避免预先只留同向交易造成自我验证。

除pair数外，报告唯一股票成交/ETF成交有配对的比例、交易总数、每1000笔股票成交的excess和每分钟率。同一ETF成交可以配多笔股票成交，不代表多个独立投资者；不能用pair倍增当样本规模。

有限敏感性：用接收时间重算方向/直方图；另移除每秒前200毫秒的记录重算20微秒/背景计数，并明确它只是周期性交易检查。两种不同时间轴不能互证时钟绝对正确。A/B/C分别交付，不拼成一条事件效应。

## 4. 后续报价证据：速度和有信息含量分开

逐笔配对先回答交易活动，不能直接回答谁生产信息。对每一条唯一ETF成交按是否在20微秒内有同向股票配对标记；多重配对只记一次，另记录multiplicity。对股票成交对称处理。

每笔已签名成交以严格可用的交易前mid m_pre和成交价 p，取1秒、5秒、60秒后mid m_h，报告：

    effective_spread = 2s(p−m_pre)/m_pre
    signed_mid_change(h) = s(m_h−m_pre)/m_pre
    realized_spread(h) = 2s(p−m_h)/m_pre

单位bp，s=+1买、−1卖。检查effective_spread = realized_spread + 2×signed_mid_change。m_h按同一信息时间轴选择；消息内报价若是交易后状态不能当m_pre。缺端点不填0，报告可用分母。逐笔先算、聚合输出中位数和均值/分位数；不导出原始逐笔价格。

同向配对组与未配对组在同场所、同窗口、同5分钟格内比较，同时展示两组事前quoted spread和成交量分布。格内任一组缺失则无比较；不把原始组差当因果。方向推断版本另列；收益正/负都保留。60秒响应不是永久价格冲击或知情交易身份证明。

A模块只用新tick重画股票与SPY的bid/ask/mid/spread及首分钟放大图；原有一秒篮子作为不同分辨率的背景。仅两证券tick时禁止宣布整个篮子领先。无需同时重跑前一稿全部onset阈值和所有微秒quote交叉配对。
