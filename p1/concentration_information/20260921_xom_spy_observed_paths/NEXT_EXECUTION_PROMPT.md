1. **定位、复用、必要补数。** 从既有 manifest 定位六日期、SPY 和发行人股票的文件及历史身份。先查精确文件，避免递归扫描或重哈希整个 SCC。每个锚点请求范围为 -15 至 +75 分钟；±1 分钟敏感性所需 padding 一并计入。重叠请求合并为同一证券、feed、日期的区间并集。已有文件缺少 padding 时保留可计算端点，不将整事件判缺。

   主要 feed 固定为 XNAS.ITCH bbo-1s；ARCX.PILLAR 作独立场所对照。其他既购 feed 可列补充。主要 feed 不足时保留缺失，并将其他 feed 明确标为替代诊断，不按结果选择。原 manifest 的 UNH 缺口需实际核实；文件存在不等于发行人和 SPY 都有报价。

   用户执行本 prompt 即授权在 SCC 读取这六个事件所需报价、时间、状态与历史身份，计算派生结果。精确缺口可沿用既有购数许可，在可核实的剩余额度内补齐，无需逐单报价请示。仅使用已经配置的认证；缺认证或可靠余额时完成全部已有数据计算，写明具体未运行请求。不得从旧聊天复制凭据、充值、订阅、重复付费或扩成整日／整年采购。原始许可行留 SCC，本地与 Git 只保存代码、文档、派生指标和质量汇总。

2. **直接修正报价状态选择。** 旧单事件代码先丢弃不满足 valid() 的记录，再寻找 target 前最后一条报价。这可能绕过后续无效状态。新入口先按 instrument/publisher/ts_recv 保留状态演变，再判断目标时点状态：有证据的撤销、无报价或数据中断不能被旧有效报价覆盖。同时间冲突、乱序、undefined 和单边报价按 schema 含义处理并记录；单纯没有新记录不等于报价失效。

   只核对相关 schema 文档与六事件的实际记录，做少量针对性测试：有效后撤销、没有更新、单边状态、时间冲突和边界时点。未知持续有效性明确标注，仍可交付最后观察到的有效路径作为有标签的诊断。先用 XOM January 对照旧端点，报告实际有几个端点改变；不存在受影响记录就沿用已复算数值。无需重做其他历史审计。

3. **完成同一套可比图表。** 每个锚点 baseline 为前 5 分钟，端点为 0、+1、+5、+15、+30、+60 分钟。对 SPY 和股票分别计算 bid、ask、mid 的 baseline=100 路径，补齐上一轮仅有完整 mid 路径的问题。使用 bbo-1s 的 ts_recv 时间语义，不按 ts_event 代替。对超出文件覆盖的目标留缺失，不把末端报价携带到已知档案范围外。

   主图使用共同 baseline mid 归一化 bid/ask/mid 以展示价差；如另外按各侧自己的 baseline 归一化，明确标识。端点至少给 mid 变动、价差、baseline 与终点报价年龄、观察／未知／无效原因及 anchor 敏感性。保留盘前与盘后区别。

   加入简单的跨价差变化区间：下界 `bid_end / ask_base - 1`，上界 `ask_end / bid_base - 1`，统一换算 bp。它说明观察到的价差是否足以解释变动，不是置信区间，也不保证可成交；状态、同步和规模限制照实保留。展示 raw mid 与此区间，不能为得到清晰图删掉宽价差点。若异常只出现在一个场所或一个成分，给出诊断说明。

4. **加入经济尺度说明。** 如已有许可的公告前 SPY 月度报告中能明确匹配发行人，读取其报告权重，并展示 `报告权重 × 发行人回报` 的量级以及 SPY 实际回报。这是静态权重近似，用于提醒读者指数稀释的数量级；不当作事件时实际贡献、理论应有响应或 causal residual。缺权重的事件照常完成两证券图表；不要重新等待完整 State Street 历史篮子。

   本轮不继续扩张旧六股票子组合。其约 2.09% 覆盖及 XOM 占代理价值 67.62% 已足以说明它不能代表 SPY。只有可可靠测量的同一经济对象，才适合随后谈 ETF 与篮子的价格发现份额；不对 SPY 与单只发行人直接套二元 IS/CS。

5. **一次交付六事件总表。** 每个事件必须占一行，即使部分缺失。逐事件报告双证券共同支持、时钟性质、端点表现、跨价差区间是否跨零、场所方向是否一致及实际缺口。统计事件数、发行人数、日期数与时钟变体数，避免把变体、venues、horizons 或重复发行人当独立样本。分开列正常公告锚点、来源冲突锚点与通知窗口；这些标签不阻止先展示路径。

   只给描述性汇总。六事件不承担总体显著性、经验功效、因果识别或同一现金流信息份额判断。新闻意外大小、本征价值和完整篮子均未测量；幅度小或不同号不证明信息未被吸收。
