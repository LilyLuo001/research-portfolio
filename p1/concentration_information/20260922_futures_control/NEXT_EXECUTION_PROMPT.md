## B. 时间轴与特征：足够支持一秒比较

核对三个数据源的 `ts_event`、`ts_recv` 定义和单位。主分析沿用既有事件时间，记录非单调、未定义、重复时间戳和 event/receive 差异；不能将接收时间称作 SIP 时间，不能把纳秒存储精度当作跨交易所同步精度。

ES 特征只含截至中心可得的原生报价状态：与现有模型相同的三个历史收益区间、相对价差、bid/ask depth、前一秒 midpoint 更新数及最近更新年龄。不使用期货未来收益或当日事后挑选的主力合约；期货价格与股票价格不直接相减，采用收益与各自单位标准化。已有股票成交扩展字段保持原处理，不新增期货成交方向研究。

报价初始化、重置、缺失和消息同时间戳顺序按来源说明处理；查询数组先验证用于查找的时间单调。持有的有效不变报价不自动算缺失；不能跨无效状态填充，不插值目标，不拼接不同合约制造秒内收益。

## C. 同目标、同支持的四模型比较

沿用最新 directional_evidence 实际执行代码，而非旧五秒配置。主目标为个股未来1秒 midpoint log return。训练12日、验证4日、测试8日，股票名单及日期均保持不变。

对每只股票，定义 B = 自身历史 + 其余22只抽样股票的报告权重篮子 + 原时间控制。估计：

- M0：B。
- M1：B + SPY历史。
- M2：B + ES历史。
- M3：B + ES历史 + SPY历史。

全部四个模型共享完全相同的目标行。保留现有训练期插补和缺失指示，目标不插补。保存 ES 覆盖；若有缺失，补充 ES 实际有效中心上的同支持比较，不能把“无法观测期货”的结果称作控制期货之后的证据。分别报告全支持、有效ES支持的日期和分母，不因某个局部缺口丢弃已完成部分。

主比较：

- SPY原增量：`1 − SSE(M1)/SSE(M0)`。
- ES原增量：`1 − SSE(M2)/SSE(M0)`。
- 给定ES的SPY增量：`1 − SSE(M3)/SSE(M2)`。
- 给定SPY的ES增量：`1 − SSE(M3)/SSE(M1)`。

同时给出原始MSE和损失差，便于在相同分母下比较。不同 G 的比值不是“信息份额”或“期货解释掉的百分比”；模型和正则化变化也可能影响其数值。负 G 表示这个预测程序没有改善，不表示来源绝无信息。

## E. 有终点的科学决定

根据效应量、区间、跨场所/网格方向和日期集中程度作一次综合判断，而非要求每个辅助格都显著：

1. `RESIDUAL_SPY_INFORMATION`：ES有实际覆盖后，SPY仍有方向一致且不由单日驱动的增量。结论为“已测ES历史之外的SPY条件预测信息”；下一步优先对一段未查看日期进行固定规格复现，并重新评估与文献的区别。不能直接跳到套利机制或集中度结论。
2. `REDUNDANT_WITH_ES_AT_THIS_HORIZON`：SPY增量加入ES后明显衰减、接近零，且区间足以排除原先量级。结论为本尺度的信息冗余证据；不据此证明期货源头、因果中介链或ETF没有作用。停止本规格的ETF独有主导叙述。
3. `COMPLEMENTARY_PREDICTIVE_INFORMATION`：ES与SPY的条件增量均稳健为正。下一步围绕互补信息而非谁取代谁，候选机制需单独证据。
4. `MIXED_OR_UNRESOLVED`：增量不精确、跨场所/时钟敏感或被一两天驱动。写明哪个观察区分不了解释，给出一个有终点的下一检验；不能自动扩年、换组或连续采购。
