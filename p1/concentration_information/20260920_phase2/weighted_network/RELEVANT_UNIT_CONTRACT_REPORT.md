# Target-relevant bounded input diagnostic

This is a small, deterministic relevance repair—not a full-network calculation. It selected the first three `ETF_ONLY_RECORDED_CLASSES` portfolio/report-date observations with at least 100 distinct frozen top-500 common-shareclass securities, ordered by portfolio ID then report date. Summing within-portfolio distinct security counts gives 635 receiver memberships and 19 top-8 issuer memberships; these are not cross-portfolio unique security counts. The JSON's `selected_receiver_security_count` and `selected_issuer_security_count` use this membership-sum denominator. It read only their holdings rows, date-valid header records, and 2022 `fund_summary2`; no event, forecast, return, or quote data was read. Exact source paths and hashes are in `RELEVANT_UNIT_CONTRACT_DIAGNOSTICS.json`.

The three selected observations yielded 991 holdings rows, 777 with positive `market_val` and `percent_tna`, no nulls in either field, and no `percent_tna` above 100. No upper-bound test was applied to dollar market values. `percent_tna` is documented as a reported percent weight of total net assets; a numerical reported-weight network does not itself require choosing a dollar TNA, but still requires the intended network definition and eligibility checks.

Each selected portfolio had one date-valid fund identifier in the mirrored header. None had a same-`caldt` positive `fund_summary2.tna_latest` record; therefore there are zero eligible rows for even an **available-fund-TNA-sum** comparison. This is a concrete same-report-date coverage gap for this bounded relevant sample, not evidence that TNA is globally unavailable. The mirror metadata documents `tna_latest` as latest month-end TNA but does not state units or a portfolio-to-fund/share-class allocation; no class-sum completeness is documented. Accordingly no class-TNA sum was treated as a portfolio denominator, no scale was fitted, and no dollar-valued weighted `L` was calculated.

`asset_dt` is an asset-composition date and is distinct from `tna_latest_dt`; no inference is drawn from its relation to the holdings report date. Backend execution telemetry: `NOT_OBSERVED`.
