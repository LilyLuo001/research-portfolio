# Decision

**`HOLD_NAMED_INPUT` — no actual event-time SPY basket is established.** The final SCC aggregate probe and an independent aggregate-only recomputation establish only a 2022-12-31 CRSP report snapshot effective 2023-01-09 and a 2023-01-31 report snapshot effective 2023-02-07. The former is a lagged report proxy; the latter is after the 06:30 ET anchor. Neither supplies a dated pre-anchor actual holding/creation basket with per-share units, cash and corporate-action treatment. The 500 rounded share-ratio count is diagnostic only and is not evidence of economic non-proportionality without fund-share and corporate-action denominators.

No forecast, actual EPS, or quote values were read; no data were purchased; no release exists. The one next action is to obtain, or document the unavailability of, State Street's historical daily SPY holdings/portfolio-composition package applicable before 2023-01-31 06:30 ET, including security IDs, per-share/Creation-Unit quantities, cash/CIL/balancing cash, corporate actions and publication provenance. A PI-approved lagged-holdings proxy would be a separate measurement object (`SPEC_AMENDMENT_PROPOSED`), not an automatic fallback.
