# 候选可反驳检验（DRAFT / NOT FROZEN / NOT RUN）

这是研究定位的技术附件，不是新全量运行授权或结果报告。先解决 point-in-time 信息集，再选定一次估计。不得据此自动打开 sealed 数据。

## 1. 对象和最小模型

观察单位建议为接收公司 i—目标财务季度 q—预测时点 t。经济公司、交易证券、财政期、信息公开时间、数据库激活时间分别建键。不可把同一期修订行或多个股票类别当作多个独立基本面实现。

候选目标 Y 是下一次相应财务期首次可核实公开的盈余实际；不是未经说明的当前修订版本。候选频率为季度基本面、日级信息时点及日收益，不需要分钟报价。

设 X 为时点 t 已公开的接收公司及宏观/行业基准信息，G 为当时已公开的巨头/同业信息，P 为该接收公司在 t 前的价格信息。所有模型的训练标签必须在训练截止前实际可得；按日历时间前推验证，禁止随机拆分同季度公司造成共同冲击泄漏。

两个不同的预测增量（损失函数先固定为标准化平方误差）：

- 总体价格信息增量：L(Y, m(X)) − L(Y, m(X,P))。
- 独有信息增量：L(Y, m(X,G)) − L(Y, m(X,G,P))。

第二个指标只是“在已指定公共信号之外的增量”，不是公司纯特质信息的无误测量；遗漏共同信号或模型误设都能污染它。G 的因子数、尺度和训练规则必须相同且事前固定，不能靠给高集中组更多预测变量制造差异。比较集中度时，同时报告标签方差、共同基本面可预测性和覆盖总量；低方差可能机械压缩增量。

模型复杂度固定；标准化、残差化、缺失值规则只用训练段拟合。跨期比较同时报告同公司支持，不用只保留存活者改善稳定性。2023 已有结果是开发信息，不因换目标就自动成为未见样本；其他年份的暴露状态也须单列核实。

## 2. 来源集中度不能凭故事指定

市值 HHI 只表示资本集中，不能充当信息集中。可构造的候选代理是分析师研究配置：预先定义公司池内，每个分析师—公司—季度覆盖关系至多计一次，再计算配置份额集中度。同时保留分析师数量、覆盖公司数和公司自身覆盖，不以修订频率机械放大某公司权重。

这仍不能测量报告内容复用或投资者真实依赖。数据若仅支持这个代理，研究标题和结论应是“研究覆盖配置与价格信息含量”，不能自动声称“巨头挤出市场信息生产”。代理是否能承担这篇论文的贡献，是未决科学问题。

全国统一季度 HHI 在季度固定效应下被吸收。不得一边声称控制全部时间冲击，一边估计同一公共时间序列的主效应。改用行业/接收者信息池、交互暴露或不同固定效应都会改变 estimand，必须显式重新定义；不能临场静默更换。

## 3. 判别组合

| 观察组合 | 合理解释 | 不允许的结论 |
| --- | --- | --- |
| 共同信号与价格增量均改善，独有信息未下降 | 与有效学习一致 | 集中化损害价格发现 |
| 共同信号改善，同时独有信息增量可重复下降 | 值得进一步验证资源替代/信息损失 | 已证明集中度导致挤出，或 ETF 是渠道 |
| 只有同步、绝对反应或反转变化 | 信息质量尚未识别 | 将振幅直接改名为效率 |
| 区间宽、结果依赖来源/时期 | 不足以判断 | 自动换年份、阈值或目标找正结果 |

以后若考察接收公司自身公告，必须同时看基本面新闻与价格反应。自身公告反应较小可以表示提前学习；较大可能表示更多新信息；反转也可能包含风险溢价变化。均不是单独的“错误定价”检验。

## 4. 识别边界与一次性执行条件

上述比较首先是预测/测量研究，不是集中度因果效应。共同基本面、产业结构、投资者需求、分析师选择及宏观变动会同时影响集中度和价格信息。加入控制或现代估计器不能自动消除此问题。先形成稳定事实，再判断是否值得找到具体的机制变化；不先挑 Bartik、RD 或政策标签。

启动任何数值试验前，一次写全：数据源版本、值字段权限、可用时点规则、实际盈余修订/调整口径、单一人口、基准与目标、训练/验证日期、主要比较、独立日历与发行人支持、推断及经济重要性阈值、缺失处理、有限敏感性与停止规则。当前这些未全部冻结，所以运行状态是 NOT_RUN。

若缺历史值口径，不用当前 Compustat 值倒填历史预测器。已知修订后的值仅可在明确“最终实现”目标定义下使用，不能冒称当时已知；这仍是目标变更，不能临场替换。
