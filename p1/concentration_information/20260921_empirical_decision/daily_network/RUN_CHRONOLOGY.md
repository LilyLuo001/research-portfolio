# Daily/network run chronology

- The specification and first outcome-free logical fixture were frozen before new daily returns were read.
- One two-block pilot then executed on SCC. It produced 3 issuer-date rows, 2 unique date/overlap blocks, 921 broad receiver-date responses and 1,347 observed positive issuer-receiver analysis rows.
- After that pilot, an implementation review found that date-only own-news and macro flags had to cover the economic interval from the preceding close, including intervening weekends and holidays. This deterministic mask correction was made after pilot responses; it was not outcome-selected. The corrected mask fixture passed locally and on SCC. The first queued full job, `7671355`, was canceled before execution for this correction.
- Full job `7671360` completed normally (`qacct` exit status 0). During its run, an early status check mistook in-progress partial outputs for termination. That mistaken diagnosis triggered a second full job, `7671406`; deletion was requested after its duplicate nature was recognized. Its final scheduler status is recorded in the execution receipt. The second code version added algebraically equivalent block cross-products and exact control-window reuse/dependence diagnostics; the estimands and point specifications were unchanged.
- Referee review then identified an issuer-SIC implementation bug: the sole loaded 2022 cutoff row was discarded by a lagged-cap filter before SIC extraction. That made all issuer SIC missing, the adjusted design rank deficient and the strict same-industry sample empty. A bounded network-only repair uses the existing H1 response panel and correct date-valid 2022 cutoff identity; it reads no new returns.
- Referee review also found that the full-year daily delisting file had been loaded without a source-side H1 predicate. H2 delisting-return values were therefore loaded into the process, although only H1 CRSP rows could join and no H2 value entered a response, model, public table or diagnostic inspection. The read now has an explicit H1 predicate. The project must not claim that every H2 response-bearing source value remained unread; the deviation is confined to this delisting input.

The initial pilot therefore does not certify the final code hash. The final code's affected calendar-span fixture and response-read predicate audit do; completed/repair receipts and public hashes bind substantive results.
