## 脊柱零 — 价格发现的时间路径 `Speed^h`(v2.0 主结果) {#脊柱零}

H1(计划 §3):转换后,受影响股票在自身盈余公告后的价格发现**时间路径**发生位移。
**方向不预设**(GNZ 改善 vs Sammon 恶化)。分析单位:**股票 × 盈余事件**。

### 0-1. `Speed^h` — 到期限 h 已实现的盈余反应占比

| 字段 | 规格 |
|---|---|
| **数学定义** | 对股票 i、盈余事件 e、期限 h:<br>`Speed^h_{i,e} = AR_{i,e}(t_0 → h) / AR_{i,e}(t_0 → T)`<br>分子 = 从公告时刻 `t_0` 到 h 的累计**异常**收益;分母 `T` = **+1 交易日收盘**(预注册,见 D-T3-10)。<br>异常收益 = 市场模型残差(估计窗 [−250, −21] 交易日)或规模-账面市值配对调整;两版并报。<br>`h ∈ {5m, 15m, 30m, 60m, close, +1d}` |
| **数据表与字段** | **日内**:Databento TBBO(或 WRDS TAQ)成交价,仅盈余公告窗 —— 计划 §4.1。<br>公告时刻:IBES `actu_epsus.anndats` + `anntims`;与 Compustat `fundq.rdq` 双源核对。<br>估计窗:`crsp.dsf.ret` + `crsp.dsi.vwretd`。<br>`[WRDS_NEEDED: ibes.actu_epsus — 确认 anntims 字段存在且非空率;这是整条脊柱的前提]`<br>`[DATA_NEEDED: 日内成交 —— v1.0 未采购,v2.0 载荷性。见计划 §4.1 的 ¥1,665 方案]` |
| **文献口径出处** | 概念最接近 Ahn & Patatoukas (2022, *JFQA* 57(5):2022–2062, DOI 10.1017/S0022109021000235) 的"对新闻的调整速度";intraperiod timeliness 的日内推广见脊柱一 1-3。<br>`[NEED_PDF: Ahn–Patatoukas 的 speed 测度是否用比值形式、如何处理分母近零]` |
| **边界情形处理** | **(1) 公告时段三分**:盘前(开盘前)→ h 自**当日开盘**起算;盘后(收盘后)→ h 自**次日开盘**起算,"当日收盘"对应次日收盘;盘中 → 自公告时刻起算。**三类分开报告,禁止合并**(计划 §7.1)。<br>**(2) 分母近零**:剔除 \|分母\| 低于其分布 10 分位的事件;稳健性改用水平差 `AR(h) − AR(T)` 而非比值;winsorize 前后两版并报。<br>**(3) 停牌/熔断**:公告窗内触发交易暂停的事件单列,不并入主表。<br>**(4) 缺失日内报价**:该事件整体丢弃,不用日频代理填补(meta-rule 4)。<br>**(5)** 分母符号与分子相反时 `Speed^h` 为负 —— 保留,不取绝对值;它是价格反转的真实信号。 |
| **合理值域** | 主样本 `Speed^h ∈ [−1, 2]`;`Speed^{+1d} ≡ 1` 恒等(用作管道正确性 assert);`Speed^h` 对 h 单调不减在**多数**事件上成立,但不强制(反转事件例外)。 |

## 脊柱一 — 系统性盈余信息的公告前纳入 {#脊柱一}

H1: 转换后,受影响股票对系统性盈余信息的公告前纳入速度提高;效应集中于原 ETF 覆盖低、
信息环境弱的股票 (§7).

### 1-1. 盈余分解：系统性成分 vs 特质成分

| 字段 | 规格 |
|---|---|
| **数学定义** | 对每个季度 q,用截面回归将 firm earnings 分解为系统性成分和特质成分:<br>`Earn_iq = α_q + β_q · Earn_mq + γ_q · Earn_indq + ε_iq`<br>其中 `Earn_mq` = 市值加权市场盈余(排除 i 自身),`Earn_indq` = 行业盈余(SIC 2位码 × q截面均值).<br>系统性成分 = 拟合值 `ŷ_iq = α̂_q + β̂_q · Earn_mq + γ̂_q · Earn_indq`;<br>特质成分 = 残差 `ε̂_iq`.<br>`[NEED_PDF: GNZ 2021 exact regression equation — LHS variable (raw EPS? scaled by assets? price?), lag structure, whether market earnings exclude industry or not, estimation method (OLS or WLS?)]` |
| **数据表与字段** | Compustat Quarterly (`compq`): `epspxq` (primary EPS excl. extraordinary items) ÷ `prccq`×`cshoq` for price-scaling; `sic` for industry; `cshoq`×`prccq` for market-cap weighting.<br>`[WRDS_NEEDED: compustat.comp.fundq — confirm exact earnings field GNZ use; run `pull.py discover --table compq --columns epspxq,epspiq,niq,saleq,cshoq,prccq,sic`]` |
| **文献口径出处** | GNZ (Glosten, Nallareddy, Zou 2021, *Management Science* 67(1):22–47; IDEAS/RePEC: https://ideas.repec.org/a/inm/ormnsc/v67y2021i1p22-47.html). FERC style follows Collins, Kothari, Shanken, Sloan (1994, *JAE* 18(3):289-324; ScienceDirect: https://www.sciencedirect.com/science/article/pii/0165410194900248). |
| **边界情形处理** | (1) 每季度要求 ≥ 20 firm-years in the market regression — drop quarters with thin cross-sections. (2) Exclude firm i from its own industry mean when constructing `Earn_indq`. (3) Outliers: winsorise earnings/price at 1st and 99th percentile before estimating `β_q, γ_q`. (4) Firms with missing `epspxq` or `prccq` dropped for that quarter; no imputation. (5) `[NEED_PDF: GNZ exact sample filter — minimum history, exchanges (NYSE/AMEX/NASDAQ?), share code restrictions]` |
| **合理值域** | `sys_earn` ∈ [−0.20, +0.20] (in units of earnings/price); `idio_earn` similar range; |sys_earn| < |raw_earn| × 2 (decomposition should not amplify). |

### 1-2. FERC-式系数 (Future Earnings Response Coefficient)

| 字段 | 规格 |
|---|---|
| **数学定义** | Annual firm-level time-series regression (or panel with firm FE) over the pre-announcement window. Following Collins et al. (1994) adapted by GNZ to *systematic* earnings:<br>`Ret_pre_iq = α + β₁·SysEarn_{i,q-4} + β₂·SysEarn_iq + β₃·ΣSysEarn_{i,q+1..q+3} + β₄·ΣRet_{i,q+1..q+3} + ε`<br>where `Ret_pre_iq` = cumulative stock return over the **pre-announcement window** for quarter q (from day −63 to day −2 relative to the earnings announcement date, ≈ one quarter). **FERC = β₃** (coefficient on sum of three-year future systematic earnings).<br>`[NEED_PDF: GNZ exact horizons — 1-year or 3-year forward sum? quarterly or annual frequency? exact pre-announcement window definition?]` |
| **数据表与字段** | (a) Compustat Quarterly: `epspxq` as the earnings basis; scale by assets or market cap (TBD from PDF). (b) CRSP DSF (`crsp.dsf`): daily returns → cumulate over pre-announcement window. Announcement dates: IBES `rdq` field (primary) or Compustat `rdq` (fallback). `[WRDS_NEEDED: crsp.dsf columns permno, date, ret, shrout, prc; ibes.statsum_epsus rdq field]` |
| **文献口径出处** | Collins, Kothari, Shanken, Sloan (1994, *JAE*; URL above). GNZ (2021, *MS*; URL above) apply to systematic earnings component specifically; their adaptation is the direct template. |
| **边界情形处理** | (1) Require ≥ 8 pre-announcement-quarter observations per firm for firm-level FERC; drop firms with < 8. (2) Winsorise `Ret_pre_iq` at 1%/99%. (3) If the announcement date is on a non-trading day, shift to the next trading day. (4) Pre-announcement window is contaminated if a prior-quarter announcement falls inside it — flag those observations as `ferc_contaminated = 1` and exclude. (5) Missing future earnings at q+1..q+3 causes the FERC row to be dropped (no imputation). |
| **合理值域** | `ferc` ∈ [−1.0, +3.0] (coefficients in a return-on-earnings regression; GNZ report values around 0.2–0.5 for the systematic component); t-stat on β₃ should be finite (|t| < 30). |

### 1-3. IPT — Intraperiod Timeliness

| 字段 | 规格 |
|---|---|
| **数学定义** | Per quarter q and firm i: IPT measures the fraction of the quarter's total systematic-earnings-related return that is incorporated *before* the announcement.<br>`IPT_iq = CAR_pre_iq / |CAR_total_iq|`<br>where `CAR_pre_iq` = cumulative abnormal return over the pre-announcement window (day −63 to day −2); `CAR_total_iq` = cumulative abnormal return over the full announcement window (day −63 to day +1, or +6, per GNZ convention).<br>`[NEED_PDF: Beekes–Brown (SSRN 938982) exact IPT formula; GNZ's exact window for IPT — pre-announcement only, or proportion of [−63, +6] total? Whether denominator is absolute value of total or signed total.]` |
| **数据表与字段** | CRSP DSF for daily returns. Announcement dates from IBES `rdq`. Abnormal return = raw return − DGTW benchmark return (see 脊柱二, variable 2-3). `[WRDS_NEEDED: same as FERC]` |
| **文献口径出处** | Beekes and Brown (2007, SSRN 938982; URL: https://papers.ssrn.com/sol3/papers.cfm?abstract_id=938982). GNZ (2021, *MS*) adaptation is the direct template. |
| **边界情形处理** | (1) If `|CAR_total_iq| < 0.001` (announcement had near-zero total price response), set `ipt_iq = NA` — cannot meaningfully compute a ratio with near-zero denominator. (2) Clip `IPT` at [−5, +5] before using in regressions (extreme values signal data error). (3) Require same minimum pre-announcement window as FERC (≥ 8 quarters); drop firm-quarter otherwise. |
| **合理值域** | `ipt` ∈ [−2, +2] after clipping; central mass should be [0, 1] (most pre-announcement incorporation is in the same direction as eventual total); negative values are valid (price moves against eventual outcome). |

### 1-4. Hou–Moskowitz Price Delay D2

| 字段 | 规格 |
|---|---|
| **数学定义** | Weekly return regression estimated over trailing 52 weeks ending the week before the event quarter begins:<br>Unrestricted: `R_it = α + β₀·R_mt + β₁·R_m,t−1 + β₂·R_m,t−2 + β₃·R_m,t−3 + β₄·R_m,t−4 + ε_it`<br>Restricted: `R_it = α + β₀·R_mt + ε_it`<br>**D2 = 1 − R²_restricted / R²_unrestricted** (higher D2 = more delay).<br>`[NEED_PDF: GNZ confirm 4 lags vs different number; weekly vs daily frequency; rolling vs annual estimation window]` |
| **数据表与字段** | CRSP DSF for daily returns → aggregate to weekly (Wednesday-to-Wednesday or calendar week; choose consistently). Market return = value-weighted CRSP market (`vwretd`). `[WRDS_NEEDED: crsp.dsf columns permno, date, ret, vwretd or crsp.dsix for market index]` |
| **文献口径出处** | Hou and Moskowitz (2005, *RFS* 18(3):981–1020; Oxford Academic: https://academic.oup.com/rfs/article-abstract/18/3/981/1617714). D2 is the R²-based variant they report as the primary measure. |
| **边界情形处理** | (1) Require ≥ 40 weekly observations (of 52 possible) for both restricted and unrestricted regressions. (2) If R²_unrestricted ≈ 0 (< 1e−6), set `delay_d2 = NA` to avoid division instability. (3) If R²_restricted > R²_unrestricted (numerical issue), clip D2 at 0. (4) Compute at the stock-quarter level: use weeks in the quarter before the earnings announcement as the estimation window endpoint. |
| **合理值域** | `delay_d2` ∈ [0, 1] by construction; typical range 0.10–0.60 for individual stocks; values > 0.99 indicate a suspiciously poor restricted fit and should be flagged. |

### 1-5. Peer-Announcement Response

| 字段 | 规格 |
|---|---|
| **数学定义** | For basket peers in the same ETF that announce earnings *before* stock i's own announcement in the same quarter: the immediate cumulative abnormal return of stock i around peer j's announcement date.<br>`PeerResp_ij = CAR_i[−1, +1]` around peer j's announcement date, where abnormal return = raw return − DGTW benchmark (§7, 脊柱二 variable 2-3).<br>Aggregate to stock-quarter level: `PeerResp_iq = Σ_j (SUE_jq · CAR_i[−1,+1]@j) / N_peers`<br>where SUE_jq = earnings surprise of peer j (DECISION_NEEDED below), scaled so the regression coefficient has a natural interpretation.<br>Primary outcome: the regression of `PeerResp_iq` on `ConvExp_iq` (treatment), DiD specification. |
| **数据表与字段** | Basket membership from `events_merged.csv` (T1 output). SUE from IBES (analyst) or Compustat (time-series) — **DECISION_NEEDED D1** below. Announcement dates from IBES `rdq`. CRSP DSF for returns. `[WRDS_NEEDED: ibes.statsum_epsus, crsp.dsf]` |
| **文献口径出处** | SUE-IBES: Livnat and Mendenhall (2006, *JAR* 44(1):177–205; Wiley: https://onlinelibrary.wiley.com/doi/abs/10.1111/j.1475-679X.2006.00196.x). SUE-TS: Foster, Olsen, Shevlin (1984, *TAR* 59(4):574–603; Stanford GSB: https://www.gsb.stanford.edu/faculty-research/working-papers/earnings-releases-anomolies-behavior-security-returns). | **边界情形处理** | (1) Only include peers that announce in the 63-day window *before* stock i's announcement (peers that announce after i's announcement are excluded from PeerResp). (2) Require ≥ 1 peer announcement in the window; if no qualifying peers, set `n_peers = 0` and `peer_resp = NA`. (3) Exclude peers from same parent company (same 6-digit CUSIP prefix) to avoid self-announcement contamination. (4) If peer and own announcement are on the same day, exclude that peer. |
| **合理值域** | `peer_resp` (excess return): daily CAR ∈ [−0.10, +0.10] per event; extreme values beyond ±30% over 3 days should be flagged as data errors. `n_peers` ≥ 1 for non-NA observations. |

## 脊柱二 — 收益指纹：永久 vs 回吐 {#脊柱二}

H2: 用永久/回吐分解区分"信息式纳入"(H2a: 更快纳入 + 无回吐)与"价格压力式纳入"(H2b: 更快"纳入" + 20–120天显著反转) (§7).

### 2-1. 事件集定义

| 字段 | 规格 |
|---|---|
| **数学定义** | Two event types, analyzed separately (§7 — "两类事件分开做"):<br>• **Own-announcement events**: earnings announcement of the converted stock i itself. t=0 = IBES `rdq` (primary) or Compustat `rdq` (fallback).<br>• **Peer-announcement events**: earnings announcement of basket peer j ∈ basket(i). t=0 = peer j's IBES `rdq`. Stock i's returns are tracked around peer j's announcement. |
| **数据表与字段** | Basket membership: `events_merged.csv` (T1 output, col `basket_permno`). Announcement dates: `ibes.statsum_epsus` field `rdq`. `[WRDS_NEEDED: ibes.statsum_epsus columns rdq, ticker, cusip]` |
| **文献口径出处** | §7 of `docs/基金转换实验_博士研究计划.md` — the plan specifies both event types. No additional citation needed (design choice, not a borrowed variable). |
| **边界情形处理** | (1) Exclude own-announcement events where two announcements of the same firm fall within 5 trading days (merged announcement contamination). (2) For peer events: only include peers from the same ETF basket; exclude the announcing peer if it is also a treated stock in the same wave (to avoid cross-contamination). (3) Exclude events within 10 trading days of the conversion effective date (transition window). |
| **合理值域** | N_own-announcement events: at least 2 per stock per year on average. N_peer-announcement events: larger, proportional to basket size. |

### 2-2. CAR 路径 [0, +120]

| 字段 | 规格 |
|---|---|
| **数学定义** | For each event, cumulate daily abnormal returns from day 0 (announcement day) to day +120 (trading days):<br>`CAR_iq(τ) = Σ_{t=0}^{τ} AR_it` for τ = 0, 1, 2, …, 120<br>where `AR_it = Ret_it − BenchRet_it` = raw stock return minus **DGTW characteristic-adjusted benchmark return** (see 2-3 below). This gives a vector of 121 daily CAR values per event. |
| **数据表与字段** | CRSP DSF: `ret` (raw daily return), `permno`, `date`. DGTW benchmark return: see 2-3. `[WRDS_NEEDED: crsp.dsf]` |
| **文献口径出处** | DGTW characteristic adjustment: Daniel, Grinblatt, Titman, Wermers (1997, *JF* 52(3):1035–1058; Wiley: https://onlinelibrary.wiley.com/doi/abs/10.1111/j.1540-6261.1997.tb02724.x). Benchmark data: https://terpconnect.umd.edu/~wermers/ftpsite/Dgtw/coverpage.htm (Wermers; available through 2012). `[NEED_PDF: DGTW confirm compounding convention — cumulative sum Σ AR_t vs log-compounded (1+AR)−1; confirm portfolio rebalancing frequency during 120-day window]` |
| **边界情形处理** | (1) Require ≥ 10 non-missing return days in [0, +120]; if fewer, set the full CAR path to `NA` for that event (do not forward-fill missing returns). (2) If event window extends beyond the stock's last CRSP trading day, truncate and flag as `car_truncated = 1`. (3) Delisting return: use CRSP `dlret` on the delisting day; if missing, impute −30% following Shumway (1997) convention. (4) Benchmark return is matched at the start of the event month; rebatch the matching portfolio at the start of each subsequent calendar month during the 120-day window (`[NEED_PDF: DGTW rebalancing frequency — confirm monthly vs. quarterly re-sort]`). |
| **合理值域** | `CAR(τ)` ∈ [−1.0, +2.0] for τ ≤ 120 (longer windows allow greater magnitude); median CAR(120) should be near 0 for balanced control sample; single-event CAR(120) > +5 or < −2 should be flagged as outlier (do not drop, but log). |

### 2-3. DGTW 特征调整基准

| 字段 | 规格 |
|---|---|
| **数学定义** | Match each stock to one of 125 (5×5×5) DGTW characteristic portfolios at the start of each calendar month:<br>• **Size**: market cap quintile breakpoints from NYSE stocks only; all stocks (NYSE+AMEX+NASDAQ) assigned to quintiles.<br>• **Book-to-market**: all-stock BM quintile; BM measured with 6-month lag (using most recent fiscal year-end BE and market cap 6 months prior to the sort month).<br>• **Prior 12-month return (momentum)**: compound return from month −12 to month −2 (skipping the most recent month).<br>Benchmark return for stock i in month m = value-weighted return of all stocks in the matching 5×5×5 cell in that month. |
| **数据表与字段** | CRSP monthly file (`crsp.msf`): `ret`, `shrout`, `prc`, `permno`, `date`. Compustat annual (`comp.funda`): `ceq` (book equity), `csho`, `prcc_f`. CRSP-Compustat link (`crsp.ccmxpf_lnkhdr`). `[WRDS_NEEDED: all three tables; confirm the DGTW benchmark file maintained by Wermers is accessible or must be reconstructed]` |
| **文献口径出处** | DGTW (1997, *JF*; Wiley URL above). Benchmark portfolio data: Wermers, R. (maintained at terpconnect.umd.edu/~wermers/ftpsite/Dgtw). |
| **边界情形处理** | (1) Stocks with negative or missing BM are assigned to the bottom BM quintile (standard convention).
