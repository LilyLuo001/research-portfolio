## 1. 真实拆股集成测试的逻辑是循环的

### 错在哪

`p1/tests/test_gate0_continuity.py::test_direction_against_a_real_crsp_split`
声称用真实 CFACSHR 变动验证"调整后份额 = 原始份额 × CFACSHR"这个方向。
它取一次真实的因子变动,然后**自己造出**前后的原始份额:

```python
raw_pre, raw_post = 100.0, 100.0 / float(row["ratio"])
```

即假定"原始份额与因子成反比"。**这句假定与被检验的约定是同一句话。**
测试的原始份额一侧是从待检约定推导出来的,因此它只能证明自洽,
不能证明方向。文档字符串同时写着"hold shares constant across it",
与代码相反——两种说法都不对:真实拆股中,在管理人零交易的情况下,
**原始份额是会机械变化的**。

### 改成什么

新的 `test_direction_against_real_crsp_corporate_actions` 用 CRSP **自己报告的
SHROUT**,它与 CFACSHR 是独立的两列:

* 取所有 CFACSHR 发生变动的 permno-月(真实公司行为);
* 对两个方向各算一次**调整后份额序列在该月的相对跳跃**
  (multiply:`shrout × cfacshr`;divide:`shrout / cfacshr`);
* 要求冻结方向(multiply)的中位跳跃**显著小于**反向,且绝对量级接近零;
* 同时要求**原始**序列的中位跳跃远大于调整后的——否则这批"公司行为"
  根本不足以区分方向,测试应当跳过而不是给出虚假通过。

用中位数而非单个事件,是因为 SHROUT 也会因增发/回购在同月变动;
单个事件无法判定,一个总体可以。

配套的 `test_adjustment_cancels_a_real_action_on_a_real_holding`
在一次真实事件上端到端检验:持有恒定股份**比例**的基金,按 CRSP 观测到的
SHROUT 变动缩放头寸,调整后的 `share_turnover` 必须约为 0。

**CRSP 约定本身现已由 owner 外部核实**(份额/成交量乘以累计份额因子);
上述测试的作用是**在容器内用数据再确认一次**,而不是替代它。

### 因子必须按持仓 as-of 日期连接,不是按申报日期

N-PORT 的份额是 `genInfo/repPdDate`(Item A.2,"信息所属日期")的持仓,
申报日 (`filed`) 可以晚 30–60 天。**按 `filed` 连接 CFACSHR,会把一个 3/31 的
份额数用 5/30 的因子调整**——四月的拆股不但没被消掉,反而被**引入**,
而且事后两个数字看上去都合理。

实现:

| 位置 | 变更 |
|---|---|
| `build_nport_convexp.parse_nport` | 解析 `repPdDate` / `repPdEnd`,随 parsed 返回 |
| `build_nport_convexp.holdings_asof` | 取 `repPdDate`;**缺失则抛 `MissingAsOfDate`**,绝不回退到 `filed` |
| `main()` | 无 `repPdDate` 的基金进 `NEED_HUMAN_funds.csv`(`reason=no_repPdDate`) |
| ConvExp 行 | 新增 `holdings_asof_min` / `holdings_asof_max`(合并多基金时两者可不同) |
| `compute_continuity.factors_asof` | 按 as-of 日期取**不晚于该日**的最近因子;不前视、不默认 1.0、超 7 天缺口拒绝 |

`ops/contracts/conv_exposure_free.yaml` 中这两列与 `val_usd` 同为 **PENDING**,
必须与重建后的 parquet 同一个 commit 落地。

### 月频 CFACSHR 够不够?—— 测,不要假设

`compute_continuity.monthly_factor_sufficiency(asof_dates, daily_panel=None)`
从**真实日期**回答,而不是断言:

* 有 as-of 日期不是自然月末 → `insufficient`(月频文件根本没有该日观测);
* 全是月末但没有日频面板 → **`unknown`(NEED_HUMAN)**,不是 `sufficient`
  ——月内的因子变动在月频文件里看不见;
* 有日频面板 → 逐 (证券, 日期) 比较 as-of 日因子与月末因子,列出不一致者。

因此 `crsp.dsf` 的拉取新增 `cfacshr` / `cfacpr` / `shrout`
(`p1/wrds/tables.yaml`),并加了 `monthly_cfacshr_sufficiency` 的
NEED_HUMAN 断言:**在该函数返回 `sufficient` 之前,Gate 0 必须用日频因子。**

## 2. 发起人层 WCR + 首发起人样本 **不是**重复股票依赖的解

### 错在哪

计划 §15.3.0 曾用"389 只处理股票中只有 20 只跨发起人(5.1%)"
推出"发起人重抽样已覆盖 94.9% 的相关依赖",并把
"每只股票只保留首个发起人暴露"当作对剩余 5.1% 的补救。两处都不成立:

1. **分子只数了处理股票。** stacked 样本的绝大多数行是**对照**,
   而对照跨波次被大量重用(实测:2,241 只股票中 1,541 只出现在多个波次,
   单只最多 23 次)。跨发起人的同股重复主要发生在 20/389 从未计入的那一侧。
2. **分母也错了。** 相关分母是**最终回归样本**,不是处理股票数。
   在最终样本上没测过之前,任何覆盖率都是无据数字(元规则 1)。
3. **"首发起人样本"是样本修改,不是推断程序。** 丢掉跨发起人重复的股票,
   并不为**保留下来的行**提供正确的标准误。

### 改成什么

| | v2.1c | v2.1d |
|---|---|---|
| headline 推断 | 单向发起人层 WCR | **(发起人, 股票) multiway wild bootstrap**(施加原假设) |
| 单向发起人 WCR | 主 | 补充敏感性 |
| 双向 CRVE | 补充 | 补充 |
| 首发起人样本 | 主表两版之一 | **去重稳健性检验(降级)** |
| "覆盖 94.9%" | 正文论证 | **删除**,直到在最终样本上测出 |

**依赖结构保持 (发起人, 股票) 双向**——这是经济上的结构(转换决策在发起人层、
重复测量与对照重用在股票层),不因某个推断程序只支持一维而降维。
簇数少这一事实要求主程序是 wild bootstrap 而非渐近 CRVE,
但**不允许它把维度砍掉**。

# 附录 v2.1f(2026-08-28)—— 基准冻结、映射目标更正、HHI 降格

owner 指示:**P1 设计不再修订**;A7 方法族与 crosswalk 架构已批准。以下四项据此落定。

## 1. CAR 基准:冻结为**唯一**主基准

原答案 D-T3-11 是"市场模型与 DGTW 两版并报"。**不合格**:两版都可能被称作
headline,等于把基准选择留到看见结果之后。现冻结:

| | |
|---|---|
| **主基准(全部 h 统一)** | **日内市场模型**:`AR_i(t_0→h) = r_i(t_0→h) − β_i · r_mkt(t_0→h)`,市场腿取**与股票腿相同的日内起止时点**,β 用日频 [−250,−21] 估 |
| 稳健性 | ~~DGTW 式配对(仅日频及更长期限)~~ → **v2.1g 收窄为"仅月度分辨率"**、β ≡ 1、市场+行业、缩放 α̂ |

**全部 h 必须用同一基准**(D-T3-18):主交付物是 β_h 的**形状**,若某个 h 换了基准,
该点的跳变分不清是信息并入的时间路径还是基准换挡。**一条基准会变的曲线不是曲线。**

## 2. 日内期限禁用 DGTW —— 已核验,不是推测

**核验结果(2026-08-28,依据本仓库自身规格)**:`变量规格书.md` 2-3 定义的 DGTW 是
**每个日历月初**做 5×5×5 特征配对,基准收益是该 cell 的**月度价值加权收益**,
数据源 `[WRDS_NEEDED: crsp.msf]`。**因此不存在任何日内时点上的 DGTW 基准值。**

用它去定义 5m/15m/30m 的异常收益,减掉的是一个在五分钟内近似恒定的量:
`AR` 与原始收益几乎相同,基准形同虚设,而表头仍写着"特征调整"。**这不会报错,
只会给出一个看起来合理的数**——所以规则必须是可执行的,不能只写在文档里。

`p1/pipeline/benchmark_policy.py`:

* `assert_benchmark_allowed("dgtw", "5m")` → raise(并解释为什么);
* `assert_curve_uses_one_benchmark({...})` → 混合基准 raise;
* `assert_is_headline("dgtw")` → 稳健性基准冒充 headline raise;
* 未命名的 `"characteristic_adjusted"` → raise("Name the exact construction")。

若日后真的构造了**在相同日内时点上**的特征组合收益,那是一个**新的稳健性提案**,
走正常流程重新登记——不是放宽这个检查。

**采购影响**:`crsp.ermport` 由"dead weight"改为**可选(仅稳健性)**——
headline 不依赖它,但 DGTW 仍是日频及脊柱二 [0,+120] 的事前指定稳健性基准。

## 3. crosswalk 的映射目标:**决策主体**,不是任何标签

v2.1e 我写成"共享系列信托的经济发起人**就是**发生转换那只 series 的次级顾问"。
**这是把一个标签换成另一个标签,同类错误。** owner 更正后的目标是:

> **映射到"合理地产生了转换决策、并会传导共同组织冲击"的经济主体。**
> 不是法律信托,**也不自动是次级顾问**。

有时决策在次级顾问;有时在信托自身的顾问;有时在**一次性转换了多只被次级顾问管理的
series 的分销平台**——后者恰恰意味着这些 series **共享**冲击,按次级顾问拆开会**高估**
独立性。问题永远是:**谁决定的,谁的冲击是共享的。**

**`AMBIGUOUS` 是允许的答案。** 治理结构确实无法判定时,填 `AMBIGUOUS`,
并在 `evidence_locator` 里写清查了什么、为什么没定论。**不得塞进启发式分组**:
被迫归组的行是"看起来已定的未知",簇数会自信地算错,而下游无从察觉。
`ambiguous_families()` 返回这些行,主估计**必须显式处理**——
headline 同时报"每个 ambiguous 自成一簇"与"并入最佳候选组"两版;
若结论在两版间移动,那本身是关于 crosswalk 承重多少的发现,**如实陈述,
不得靠挑好看的一版解决**。

## 4. 逆 HHI 降格为诊断

v2.1e 我写成"有效簇数才是决定 bootstrap 表现的数"。**过强。**
逆 HHI 只回答"多少个等大簇会有同样的集中度",别的都不回答。
bootstrap 的有效性还取决于:**被处理**的簇有几个、处理如何分布在簇之间、
个别簇对 β_h 的杠杆、以及所选变体与加权维度的性质——
一个样本可以在规模上很均衡,却仍然靠一个被处理的簇支撑。

因此:**不设阈值**,与另外三项输入及留一发起人诊断(§15.3.2)一起读,
**不得作为 `bootcluster()` 选择的唯一理由**。决策记录里新增
`treated-cluster leverage` 一行,理由栏改为"四项事实**合起来**"。

# 附录 v2.1g(2026-08-28)—— 两项实现一致性检查

owner 指示:**不改设计**;WRDS/日内执行前只做两项一致性检查,外加一处措辞更正。

## 1. 主公式冻结,含截距处理

v2.1f 写的是 `AR = r_i − β_i · r_mkt`,**没说 α̂ 怎么办**——这正是漏洞:
`[−250,−21]` 的日频市场模型同时估出 α̂ 与 β̂,而 **α̂ 是每交易日的漂移**,
直接减到 5 分钟收益上等于多减约 78 倍(6.5 小时交易日)。

**冻结(D-T3-22)**:

$$AR^h_{i,e} = R^h_{i,e} - \hat\beta_i R^h_{m,e}$$

**不含截距,全部 h 同一条公式。** 理由与结果无关:

* **原样减 α̂** —— 量纲就错;
* **按期限缩放 α̂·(h/D)** —— 需要一个**日内漂移分配约定**(等分?按成交量?
  按波动?),本项目从未事前指定,冻结之后临时发明一个就是新增自由度;
* **不减 α** —— 唯一能让 5m 到 +1d 用同一条公式的选择,而 D-T3-18 要求如此
  (主交付物是 β_h 的**形状**)。

**代价写进论文**:`AR^h` 保留了该股在 h 内的期望漂移。两条结构性缓解:
(i) 估计对象是与**带符号 SUE** 的交互系数,与 SUE 不共变的漂移不载荷到 β_h;
(ii) ≤1 日的漂移相对盈余公告 CAR 低若干数量级。
**稳健性并报**:`AR^h = R^h − α̂·(h/D) − β̂ R^h_m`,同样对全部 h 统一施加。

**与脊柱二的差异必须写明(D-T3-23)**:`outcomes_spine2.py` 的日频路径用
`AR_t = ret_t − α̂ − β̂·mktrf_t`,在**日频**上量纲正确,保持不变。
因此 `CAR^{+1d}` 与脊柱二 `CAR[0,+1]` **并不恒等**,相差约 α̂ × 1 日。
管道一致性 assert 必须比对**脊柱二 α 强制为 0** 的版本——否则那条 assert 必然失败,
而"修好"它最省事的办法恰好是把 α 装进脊柱零,即把量纲错误装回来。
