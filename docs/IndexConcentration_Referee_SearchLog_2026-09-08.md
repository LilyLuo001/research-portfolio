## Access conditions

Outbound HTTPS in this session is governed by an egress policy that denied CONNECT to every
publisher, repository, regulator and exchange host attempted. Denials were confirmed at the
proxy (`403 to CONNECT`) for:

`academic.oup.com`, `onlinelibrary.wiley.com`, `papers.ssrn.com`, `www.nber.org`,
`www.sciencedirect.com`, `pubsonline.informs.org`, `www.aeaweb.org`, `link.springer.com`,
`doi.org`, `www.federalreserve.gov`, `www.frbsf.org`, `www.nyse.com`, `www.cmegroup.com`,
`www.spglobal.com`, `indexes.nasdaqomx.com`, `ir.nasdaq.com`, `terpconnect.umd.edu`,
`archive.nyu.edu`, `www.hbs.edu`, `ideas.repec.org`, `econpapers.repec.org`,
`academicweb.nd.edu`, `www3.nd.edu`, `arxiv.org`, `en.wikipedia.org`.

**Consequence: no abstract page, publisher page, or full text was inspected.** The only
working channel was a web search index returning titles, URLs and machine-generated page
summaries. Every literature statement in the report is labelled `[SEARCH-INDEX]` on that
basis. This is a weaker evidence standard than either "full paper" or "abstract/metadata"
and the report does not adopt the package's access labels.

## Package integrity

The package's two SHA-256 values refer to source files that were not transmitted with it. A hash
of a file the recipient does not hold provides no integrity guarantee, and boundary-marker
extraction cannot be compared against anything. Recorded as a process defect in the package, not
in the plan.
