## 1. 处理定义(冻结)

**`Exposure^pre_{i,w}` = 预定的、时间不变的转换前暴露度。**

**这不是断言,是核验结果**:
- 分子:`build_nport_convexp.py::_best_nport_in_cik` 只取
  `fils = [f for f in nport_filings(cik) if f["filed"] < eff_date]`
  → 严格转换前的 N-PORT。
- 分母:`shares_outstanding` 只取 `end <= on_date`(`on_date = eff_date`)的 XBRL 值。

**是否与 Post 冗余:不冗余。** `Exposure^pre` **不是**转换前为零、转换后跳升的
时变暴露,而是**恒定的横截面剂量**。`Exposure^pre × Post` 因此是标准的
"预定剂量 × 事件后"交互——剂量-反应解释干净,处理不由结果期机械定义。
这正是 owner 偏好的形式,已经成立,无需改造。

**命名冻结**:文档一律 `Exposure^pre_{i,w}`。v2.0 从备忘转录时写的
`ConvExp_{i,t}` 是笔误(下标 t 暗示时变),已删。仓库列名 `conv_exp` 不动(契约冻结)。

**⚠️ 顺带发现的命名隐患**:parquet 的 `pre_etf_ownership` 列当前**等于** `conv_exp`
(见 `_cell_rows`),名字暗示"转换前 ETF 持股"实为转换基金持股。
**在改名或补真值之前,不得把它当 GNZ 式 ETF ownership 控制变量。**

## 2. 主估计量(冻结)

```
CAR^h_{i,e} = β_h · (SUE_{i,e} × Post_{w,e} × Exposure^pre_{i,w})
            + 全部低阶交互项 + γ'X_{i,e} + α_i + δ_{行业×年季} + ε_{i,e}
```
h ∈ {5m, 15m, 30m, 60m, close, +1d}。**主结果 = β_h 的 h-曲线。**

**为何弃用 `Speed^h` 作主结果**:`R_{0,h}/R_final` 在最终反应近零或变号时不稳定;
v2.0 用"剔除小分母 + winsorize"补救,那是**用样本筛选补测度缺陷**,且筛选规则
与处理状态可能相关。带符号 `CAR^h` 没有分母,不需要任何补救。

**`Speed^h` 降为次要/稳健**,分母规则预先声明(D-T3-10:+1d 基准,+2d/+5d 并报,
剔除 |分母| < 10 分位,三版全报)。用途是把 β_h 曲线翻译成可读的"已实现比例",
不承担识别。

## 3. 带符号 SUE(冻结)

主规格用**带符号 `SUE`**。v2.0 的 `|Surprise|` 是错误:取绝对值只识别反应**幅度**,
丢弃方向,而价格发现的经济含义是**价格向正确方向移动的速度**。绝对值规格
无法区分"更快地正确定价"与"更快地过度反应"。

**次要检验**:正/负意外不对称(`SUE⁺` vs `SUE⁻` 分别估计),
与做空可得性通路(H4)直接相关。

## 4. 推断层级(规格冻结;表需数据)

> **⚠️ v2.1a 已取代本节的选择规则。** "取最保守者"仍然是**看到结果之后**
> 再选方法,只是把准则从"最多星号"换成"最大标准误"——两者都是数据依赖的
> 方法选择。现行方案见计划 §15.3:**由误差结构事前指定**。

**现行主推断(v2.1a 冻结)= 按(发起人,股票)双向聚类。**
依据实测误差结构:处理波次背后 14 个发起人,但 Dimensional 的
W002+W003+W007 = 364/389 股票同属一个发起人——三个"独立波次"实为一个决策者,
按波次聚类会系统性高估独立性;股票维度吸收同股多事件的序列相关**与**
stacked 设计中对照观测的跨波次重复(§6.4)。两维不嵌套,故需双向。
**不选行业维度**:处理不按行业分配,共同冲击不在行业层。

其余聚类层、WCR、RI 全部报告,但**仅作稳健性,不得用于改选主方法**。

**基金替换 RI 的可交换性假设,已形式化**:
- **A1 供体池可交换性**:未转换基金本可被转换。**与 Moussawi 等直接冲突**——
  若税收驱动转换,未转换基金在未实现资本利得上系统性不同。
  **应对**:匹配特征**必须含税务代理变量**,不只是规模/类别/费率;报告匹配后平衡表。
- **A2 供体池充分性**:报告池规模、每基金匹配数、共同支撑。
  **DFA 极可能找不到可比供体**(规模与策略都罕见),其置换分布须单独说明,
  不得混入总体 p 值。

## 5. Gate 0 组合连续性 🔴 BLOCKED

**已前移为 Gate 0**(在 K1 之前),不再是稳健性。
四个测度、事前阈值、敏感性,全部冻结在计划 §9.0。

**实现**:`p1/gate0_continuity/compute_continuity.py`。
纯函数,离线自检 **18/18 通过**(v2.1a 增补股数维度)——包括关键的两条:
*一个持仓价格翻倍、零交易*的组合,`share_overlap = 1.0` 且被标注为
"PRICE move, not rebalancing"——**价格变动不得被误读为再平衡**(v2.1a 第 4 项);
以及
*同名但完全重新配权*的组合,`name_jaccard = 1.0`(误导)而
`weight_overlap = 0.2`(正确)。这就是为什么 headline 测度是权重重合度而非名称重合度。

**v2.1a 增补**:同时报告**股数**连续性(`share_overlap`/`share_turnover`/
`n_traded_out`)。价值权重会随价格移动,股数不会——股数只在经理实际交易时变。
两者并报才能区分"经济暴露变了"与"经理动手了"。
**0.80 是操作性切点,不是经济上的自然断点**:交付物是**连续分布** +
0.70/0.80/0.90 敏感性,`classify` 仅用于样本记账,不得用于"高/低连续性"的经济对比。

**为什么阻塞**:需要**转换后第一期 N-PORT**。committed 管道只取
`filed < eff_date`,后侧数据在本仓库中**不存在**,也无法从现有数据推导。
需 SEC 出口,与 ConvExp 重建同批执行。

**未实现 `--holdings` 读取是刻意的**:在后侧 N-PORT 的 schema 未知时写读取器,
等于对猜测的 schema 写连接逻辑 —— 那正是静默 join bug 的来源。

## 6. 日内事件时点规则(冻结;供应商覆盖待核)

| 类别 | 公告时刻(ET) | **h 的零点 `t_0`** |
|---|---|---|
| RTH 盘中 | 09:30–16:00 | **公告时刻本身** |
| 盘前 | 00:00–09:30 | **当日 09:30 开盘** |
| 盘后 | 16:00–24:00 | **次日 09:30 开盘** |

**明确回答**:盘中自公告时刻起算;盘前/盘后自**下一个正常时段开盘**起算。

> **⚠️ v2.1a 更正本节的自相矛盾。** 上一版同时写了"自公告起算则 `CAR^{5m}` 恒为 0"
> 与"盘前/盘后 `CAR^{5m}` 机械性偏高"。两者不能同时成立。
> **在已采用的规则下(`t_0` = 下一个开盘),`CAR^{5m}` 是"开盘→开盘+5 分钟",
> 既不恒为零也不机械性偏高**;恒为零只发生在未被采用的替代规则下。

**两类是不同的估计对象**:RTH 测"自新闻发布起"的价格发现;
盘前/盘后测"开盘集合竞价已吸收一部分之后,剩余部分"的价格发现。
开盘跳空**被排除在 `CAR^h` 之外**,单独作为 `GapShare` 报告——
它是这两类事件的**独立结果变量**,不是对 `CAR^h` 的修正项。

**主样本规则的冻结程序**:在看到任何 `β_h` 之前,先产出纯事前样本表
(三类各自的事件/股票/波次数、处理对照分布、事件特征),据此决定并写入
`ops/decisions.md`,此后不因结果更改。**🔴 该表需 IBES `anntims`,当前 BLOCKED,
且它是日内采购的前置条件**——不知道三类各有多少事件,就无法确定买哪些
symbol×date、是否需要扩展时段。

⚠️ **两项未核实**:`anntims` 的时区与非空率(需 WRDS);
若最终纳入盘前/盘后事件,所购数据**必须覆盖扩展时段**——见第 7 项。

## 10. 反转重新定性(已改)

v2.0 写"有回吐 ⇒ H1a 的信息解释被推翻"。**该逻辑过强,已撤回。**
反转也可能来自流动性提供补偿、时变风险溢价、对照组漂移或样本期噪声;
没有反转也不证明纳入是信息性的。

**v2.1 定位**:回吐/楔形是**动态诊断与替代机制检验**——描述效应持久性,
为"价格压力"这一竞争性解释提供有信息量的证据,
但**既不自动证伪 H1,也不构成错误定价的证明**。
论文表述只能是"与…一致 / 不一致"。判定权仍在 β_h 曲线与特质/系统性分解。
