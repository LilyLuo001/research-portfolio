# Framework/census workstream

This directory answers the treatment-side part of the two September 2026
referee reports without running outcome analysis or editing the manuscript.

- `ANALYTICAL_TAXONOMY_AND_PROPOSITIONS.md` defines the seven requested
  operation types, gives boundary rules, and states/proves three invariance
  propositions.
- `CANDIDATE_ARCHITECTURE_CENSUS.md` provides a repository-bounded candidate
  ledger with explicit included/pass/fail/pending/unverified statuses.
- `CENSUS_EVIDENCE_RECEIPT.json` freezes the status vocabulary, defensible
  counts, dependence diagnostic, and hashes of the evidence used.
- `MANUSCRIPT_FRAMEWORK_SECTION.tex` is a concise section that can be adapted
  into the revised paper after the empirical framing gate is resolved.

The census deliberately does not claim to count every published measure. Its
PASS labels reproduce the existing external-admission record; candidates with
an opened primary source but no local score/mapping/support audit remain
PENDING. Referee-named measures without a verified local source/data audit
remain UNVERIFIED.
